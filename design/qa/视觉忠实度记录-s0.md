## 忠实度检查

| 检查项 | 结果 | 实施说明 |
| --- | --- | --- |
| 桌面三栏关系 | 通过 | 216 px 导航、弹性命盘主区、320 px 依据栏；各区不造成页面横向溢出。 |
| 四柱矩阵层级 | 通过 | 保留行标题与年/月/日/时四列；天干地支为主要视觉层，研究字段保持高密度。 |
| 选格与依据联动 | 通过 | 选中日柱天干后，桌面依据栏和手机底部抽屉展示同一字段、算法、引擎和来源状态。 |
| 岁序脊线语义 | 通过并收敛 | 用“输入快照—历法候选—规则绑定—本地修订”展示真实复算链，不以假大运数据充数。 |
| 气质与色彩 | 通过 | 使用纸白、墨色、玉青和少量朱砂；没有黑金、罗盘、竹叶或红绿吉凶编码。 |
| 手机功能保留 | 通过 | 360/390/412 px 均保留四柱四列、上下文、底部导航与依据入口，无页面横向溢出。 |
| 手机抽屉可见性 | 通过 | 390 px 下抽屉打开后，选中格底部为 200.75 px，抽屉顶部为 213.06 px；关闭后为 `visibility: hidden`。 |
| 内容可信边界 | 通过 | 概念图中的人物、引文和盘面占位没有进入产品；正式截图来自同一真实计算演示案例。 |

## 有意偏离概念图

1. 删除 iOS 状态栏、Home Indicator 与设备假壳，手机基线按 Android Chrome/PWA 设计。
2. 不实现概念图里的虚构完整大运；S0 只展示可验证的复算脊线。
3. 来源不足时明确显示“来源待核验”，不复制生成图中的伪引文。
4. 案例页高亮“案例库”，中央“排盘”始终保持新建动作语义。
5. 手机依据区采用平面分段，未复制概念图的卡片套卡片结构。
