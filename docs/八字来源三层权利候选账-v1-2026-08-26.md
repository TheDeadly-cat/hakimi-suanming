## 3. 条款证据

候选账固定以下公开依据：

1. [Wikimedia Terms of Use 固定修订 554823](https://foundation.wikimedia.org/w/index.php?title=Policy%3ATerms_of_Use&oldid=554823#7._Licensing_of_Content)：观察到默认用户贡献文本许可和 attribution 路径；项目例外及外部导入文本仍须逐来源核验。
2. [CC BY-SA 4.0 legal code](https://creativecommons.org/licenses/by-sa/4.0/legalcode)：观察到署名、修改标示、许可链接及改编材料相同方式共享条件；是否适用于具体字节及本项目如何合规尚未审定。
3. [Commons 重用说明固定修订 1259943424](https://commons.wikimedia.org/w/index.php?title=Commons%3AReusing_content_outside_Wikimedia&oldid=1259943424)：明确要求重用者核对每个文件的具体条件，且 Wikimedia 不保证版权状态和许可标注正确。

因此 Commons API 的 `LicenseShortName=Public domain`、`UsageTerms=Public domain`、`AttributionRequired=false` 只作为载体元数据观察保存；不会使 `carrierLayerCleared`、`redistributableSources` 或正式记录数量增加。

在线审计只读取公开 API 元数据，不保存页面正文。它以 2 个政策修订请求、4 个固定 oldid 模板解析请求和 1 个 Commons 载体批次请求，成功核对 2 个固定 MediaWiki 政策修订、4 条固定 Wikisource 修订的权利相关模板和 5 个 Commons 载体的当前权利元数据。`carrierLayers` 数组必须与来源账的所有载体锚点精确一一对应；删除 CADAL 层或只把其中一层提权都会失败。CC legal code 作为稳定版本 URL 保存，但不把 URL 可达性冒充适用性或合规判断。
