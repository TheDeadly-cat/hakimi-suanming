## 3. 不能改变的当前基线

- 普通 `npm run build` 仍必须是 `legacy-v13 / targetSchema 13`；
- v13→v16 只能是隔离候选，不自动晋级；
- 禁止用 raw IndexedDB 绕过 v16 mutation epoch/CAS；
- 八字 full v1.2 只有十六个用户分区，不接纳紫微或西洋记录；
- 紫微当前是独立 `4218` 工程资料库；西洋当前是隔离诊断/规则预览；
- Android、iOS、付费、云同步和项目托管 AI 不得偷入当前切片；
- 工程一致、第三方差分和哈希一致都不是专家真值。

## 4. 第一任务：建立受控 Git 初始基线

用户已经授权建立基线，但必须先关闭敏感范围风险。

### 4.1 已发现的风险

- 初步审计有约 2858 个未跟踪文件；
- 其中约 2284 个位于 `tmp/`；
- `tmp/pdfs/**` 含 Edge 测试 profile、Trust/VPN token 数据库、缓存、日志和其他浏览器运行状态；
- 这些内容不得读取后复制到文档，也不得暂存或提交；
- `.gitignore` 已增加 `tmp/`、Playwright 输出、环境变量文件等规则，但仍须复核其他生成物和敏感文件。

### 4.2 安全步骤

1. 使用 `git status --short --branch` 和不转义路径的文件清单重新盘点；
2. 只按文件名、大小和类型扫描敏感项，除非确有必要，不输出 secret 内容；
3. 核对 `.gitignore`、`package-lock.json`、third-party notices、离线 fixtures 和生成物边界；
4. 列出“纳入基线”和“排除基线”的顶层目录及原因；
5. 对纳入范围生成 hash manifest；
6. 运行轻量基线门：typecheck、定向测试、草案隔离、普通 build；
7. 再创建受控初始 commit，并在结果中报告 commit、文件数、排除项、构建身份和已知未跑长门。

不得删除 `tmp/` 或任何未跟踪文件来“清洁仓库”；忽略即可。不得 `git reset --hard`、`git clean` 或覆盖用户资料。

## 5. 第二任务：状态和帮助口径纠偏

完成基线后，修正仍可能存在的状态漂移：

- Help 准确说明紫微已有独立持久化工程预览，西洋已有无存储诊断/规则预览；两者无生产入口；
- 分区数、Schema、candidate、测试证据从契约或注册表派生，避免手写旧数字；
- 旧交接明确标为历史快照；
- 所有通过声明绑定 commit 或精确源码树摘要；
- v14/v15 部署历史保持 `unknown`，直到有外部证据。

## 6. 功能开发顺序

### 6.1 八字主线

优先做用户可见闭环，而不是继续增加诊断页面：

1. 首次演示引导；
2. 标准/专家信息分层；
3. 第一次真实保存后的备份健康提醒；
4. 设置 IA 拆分；
5. 未保存排盘/查询草稿的升级 reload 保护；
6. P2-05 的 CandidateSet-heavy、长文本、复杂查询、统一取消、内存和 long task。

### 6.2 紫微斗数 Web

从独立 4218 竖切继续：完整领域 fixture、现实规则审核、容量/多标签/故障矩阵、双浏览器、独立来源与权利。不得把 iztro/Fortel 差分说成专家正确。

### 6.3 西洋占星 Web

先完成严格星历与时间语义：官方工件、闰秒/EOP、时间尺度、目标中心、参考系、许可证和成功回执；再做独立保存、检索、备份、恢复和浏览器矩阵。

### 6.4 共同工作台与 Android

三个体系分别达到独立门后，再上线体系切换器和只读并列；不做自动综合评分。随后才开始 Capacitor/Android 文件、分享、返回、打印、WebView、真机和签名包。

## 7. 测试策略：轻测试、重功能

每个普通功能切片只要求：

- 相关定向单测/组件测试；
- 受影响包 typecheck；
- 一条真实浏览器主流程；
- 影响构建时验证普通 build 仍为 v13。

Schema、SW、备份、epoch/CAS、隐私、专家真值和发布晋级才运行完整重矩阵。不要为了增加测试数字拖慢所有功能，也不能借“轻测试”降低数据发布门。

## 8. 停止线

遇到以下情况立即停止扩张并修复：

- 普通 build 不是 legacy-v13；
- v14/v15 部署历史未查清却准备晋级 v16；
- 出现可写半代、半恢复、CAS 绕过或覆盖历史 Revision；
- 草案进入八字 bundle、DB、SW 或 full v1.2；
- 非预期网络请求、敏感日志或 secret 入库；
- 把工程差分写成专家真值；
- 未经权利确认把古文、现代校点、图片、字体或案例随包。
