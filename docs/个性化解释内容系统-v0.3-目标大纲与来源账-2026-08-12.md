# 个性化解释内容系统 v0.3：目标、大纲与来源账

> 日期：2026-08-12  
> 状态：执行中；八字首个竖切进入工程实现  
> 发布边界：默认发布身份继续为 `legacy-v13 / targetSchema 13`；本文不授权提升默认代、不授权紫微或西洋正式入口，也不改变 mutation epoch / CAS 约束。

## 1. 新目标

把“哈基米算命”从只展示可复算命盘事实的研究工作台，扩展为一套**结论直给、依据可追、流派可切、冲突可见**的个性化解释系统：

1. 排盘后立即呈现用户最关心的内容，而不是只给原始符号。
2. 八字先回答日主旺衰候选，再解释十神、神煞在年/月/日/时柱的位置作用，并让吉凶取向依赖全局条件而不是固定贴标签。
3. 紫微以宫位为问题入口，合参本宫、对宫、三合宫、星曜、亮度与四化，不把单星套话冒充整盘结论。
4. 西洋以行星（什么）、星座（如何）、宫位（哪里）、相位（彼此如何作用）为解释语法，再做重复主题与矛盾合成。
5. 每条解释保留来源、规则版本、适用条件、冲突状态和专家审阅状态。

## 2. 产品定位简报

- **产品身份**：本地优先、移动优先、现代东方视觉的专业命理研究工作台；不是一次性 AI 算命报告。
- **核心受众**：希望“先看懂自己的盘、再能追问依据”的简体中文学习者与研究者。
- **核心承诺**：事实层可复算；解释层有来源、有条件、有版本；不同流派冲突不会被静默抹平。
- **差异化**：同时提供竞品结果页的内容密度与研究工具的可审计性。
- **设计张力**：`直言不讳 × 证据校准`。首屏先给一句明确判断，随后展开因素账、反例条件和来源。
- **借鉴边界**：只学习工作流、信息层级和用户问题，不复制任何站点的品牌、布局、图像或受版权保护的文字。

## 5. 来源等级与准入

1. **S0 命盘算法来源**：固定版本开源库、天文/历法数据和可复算常量。可支持事实层。
2. **S1 原典/公版文本**：用于追溯传统规则，但必须经过校勘、形式化和专家复核。
3. **S2 有明确作者与版本的现代教材/论文**：只保存书目、规则摘要和必要短引；是否可内置由权利审计决定。
4. **S3 产品/竞品页面**：只用于发现功能、内容结构和用户语言，不能单独支持规则真值。
5. **S4 社区讨论**：只用于发现争议与测试问题，不进入自动断语。

任何内容条目至少包含：

## 6. 八字内容大纲

### 6.1 首屏结论

- 日主与五行。
- 旺衰五档：很弱 / 偏弱 / 相对中和 / 偏强 / 很强；不满足规则覆盖时显示“未定”，不伪造精度。
- 一句话直给：当前命局最需要什么、最容易在哪类作用上承压。
- 状态标签：流派、规则版本、候选/专家已审、是否存在冲突。

### 6.2 旺衰因素账

- 得令：月支季节与日主关系。
- 得地：其余地支根气与十二长生线索。
- 得助：天干与藏干中的印、比劫支持。
- 泄耗克：食伤、财、官杀对日主的输出、消耗与克制。
- 反例门：从格、专旺、化气、调候冲突、合化改变力量时，不下最终裁决。

首个工程版不采用竞品无法解释的“综合分数”。它输出因素和权重账，并明确：这是用于产品研究的规则候选，不是专家真值。

### 6.3 十神 × 位置

- 每柱显示透干十神、藏干十神和可见程度。
- 年柱：早年环境、家族叙事、较外层的社会印象。
- 月柱：成长制度、工作环境、稳定社会角色。
- 日柱：日干为自我参照；日支用于亲密关系/日常相处议题，不把性别刻板模板写死。
- 时柱：长期计划、产出、后期关注与下一代议题。
- 每条都分“核心作用 / 表现顺畅时 / 失衡时 / 当前相对取向”。
- 吉凶不是十神固定属性：身弱时印比通常偏助，食伤财官杀通常增加负荷；身强时方向大体相反；中和或特殊结构时标为条件性。

### 6.4 神煞

- 先做可复算命中事实：神煞名、取法、以年支/日支/日干等何者为基准、落在哪一柱。
- 再做解释：只作为附加修饰，不越过旺衰、格局与组合直接定吉凶。
- 同名异法必须分规则包；来源缺失、口诀冲突或未审时保持关闭。
- 不输出灾祸、疾病、违法、死亡、怀孕等高风险确定性预测。

## 7. 紫微内容大纲（继续保持隔离草案）

1. 选择问题宫位，而不是先堆满十四主星解释。
2. 展示本宫主/辅/煞/杂曜、庙旺亮度、四化和空宫状态。
3. 自动列出三方四正：本宫、对宫、两个三合宫，并标明每条信息来自哪个宫位。
4. 生成“本宫主题—外部牵引—资源/压力—矛盾合成”四段式摘要。
5. 单星只给基础语义；最终结论必须经过同宫组合、会照、四化、亮度与流派规则。
6. 本命、大限、流年分层显示，禁止把动态层的星曜静默写回本命。

## 8. 西洋内容大纲（继续保持隔离草案）

1. 天文事实：行星黄经、逆行、宫头、上升/天顶、相位与容许度。
2. 解释语法：行星=什么动力；星座=怎样表达；宫位=在哪个生活领域；相位=动力之间如何配合或拉扯。
3. 先呈现日/月/上升与主宰星，再呈现角宫行星、紧密相位和重复元素/模式。
4. 每项落位解释后增加“全盘修正”：相位、尊贵/失势、宫主星和重复主题。
5. 宫制、黄道体系、交点与小行星选项必须进入规则快照；没有正式 JPL 字节与审阅时不得把工程差分写成天文真值。

## 9. 直接表达模板

页面默认采用三层表达：

1. **先说结论**：`日主偏弱（候选）。当前盘里支持不足，财官食伤一侧的负荷更重。`
2. **再说为什么**：按得令、得地、得助、泄耗克列出命中因素。
3. **最后说边界**：`尚未判断从格/化格；这是规则包 v0.1 的结果，待专家复核。`

禁止用“可能、也许”把所有内容写空；不确定性通过状态、条件和冲突表达，而不是藏在含糊语气里。

## 11. 本轮证据与历史证据分界

- **历史证据**：现有排盘、十神事实、隔离紫微/西洋浏览器门、Schema 16 候选工程结果；它们不证明本轮解释规则正确。
- **本轮新证据**：2026-08-12 的参考站实走、来源账、解释契约、首个八字规则候选的单测/类型检查/浏览器结果。
- **仍未获得**：命理专家对旺衰权重、十神柱位断语、神煞、紫微星系组合与西洋解释的正式真值裁决。
