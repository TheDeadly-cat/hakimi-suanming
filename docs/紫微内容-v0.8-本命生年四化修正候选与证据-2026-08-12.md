# 紫微内容 v0.8：本命生年四化修正候选与证据

日期：2026-08-12  
状态：隔离候选、待专家复核、未正式发布  
运行边界：仅用于独立 4218 紫微工作台的已验真盘面显示投影；主应用无紫微入口

## 1. 本轮目标与结论

本轮把盘面中已有的本命生年禄、权、科、忌，从“只有标签和待审问题”推进为可直接阅读、但仍保持中性和待审的修正候选。页面选择任一目标宫位后，会在逐宫总览内：

1. 只读取该宫本宫、对宫和两组三合位中已经通过 Browser 工件验真的本命生年四化事实；
2. 对每个事实显示关系、宫位问题域、星曜、四化、既有主星落宫主线及中性修正；
3. 同时显示反向约束，避免把禄、权、科、忌直接换算成财富、职位、名声、灾祸或确定事件；
4. 若该组三方四正没有四化标记，则保持空集合，不补入宫干飞化、自化、大限或流年四化；
5. `result / goodBadOrientation / eventOutcome` 全部保持 `null`。

这是一项内容与显示层收口，不是专家真值裁决，也不授权正式入口或默认代升级。

## 2. 固定内容契约

内容版本：`ziwei.natal_transformation.neutral_candidate/0.1`

| 四化 | 中性动作标签 | 候选方向 | 必须同时显示的反向约束 |
| --- | --- | --- | --- |
| 禄 | 扩增与投入 | 放大所依附星曜在宫位问题域中的资源、活动、注意与投入 | 也可能放大成本、忙碌或消耗；不自动等同于金钱、顺利或成功 |
| 权 | 掌控与承担 | 突出执行、掌控、承担与推动 | 也可能增加压力、控制冲突或责任负荷；不自动等同于职位、权位或优势 |
| 科 | 呈现与调和 | 突出呈现、命名、解释、被识别与调和 | 被看见不等于评价有利、资格成立或行动充足 |
| 忌 | 牵挂与补缺 | 突出牵挂、反复关注、主观欠缺感与持续补位 | 感受到不足不等于现实结果恶化，也可能推动核对、修补或重新分配注意 |

固定内容共 4 条，每条都固定为：

- `reviewStatus: awaiting_expert_review`
- `publicationStatus: isolated_candidate_only`
- `expertTruthClaimed: false`
- `directOutcomeAllowed: false`
- `scoringAllowed: false`

## 3. 在线来源与采用边界

### 3.1 已采用来源

1. [紫微斗数四化｜紫微研习社 iztro.com](https://docs.iztro.com/zh_TW/learn/mutagen)
   - 用途：交叉核对四化依附于星曜、不同四化范围必须区分、四化不能直接当作固定好坏，以及禄权科忌的调节方向。
   - 边界：只重新组织中性候选，不复制网页文案；该页面也明确提示作者理解可能有误，因此不能作为专家真值。
2. [《紫微斗数全书》卷一（维基文库转录）](https://zh.wikisource.org/wiki/紫微斗數全書/卷一)
   - 用途：定位“问化禄、化权、化科、化忌星所主若何”等传统篇目与术语。
   - 边界：不采用古籍中的身份、财富、灾祸、疾病、寿命或确定结果断语。
3. [紫微斗数·流派与四化表差异概览（中文维基百科）](https://zh.wikipedia.org/wiki/紫微斗數)
   - 用途：登记流派分类及十天干四化表存在差异这一方法边界。
   - 边界：百科只作二级差异索引，不视为四化语义真值或排盘权威。

### 3.2 明确未采用的材料

- [Astrofate 四化页面](https://www.astrofate.wiki/zh/docs/four-mutations)等直接给出财富、职业、婚姻或确定结果的网络断语没有进入候选注册表。
- 用户提供的[易安居八字示例](https://www.zhouyi.cc/bazi/sm/)继续作为“排盘后给出位置化内容”的产品形态参考，本轮不把其紫微／四化表述当作来源。
- 搜索结果页、聚合转载、无明确作者或无流派口径的绝对化文本没有登记为来源。

## 4. 动态复核包

复核版本：`ziwei.palace_sanfang.natal_transformation_review/0.1`

投影必须满足以下不变量：

- 一张已验真本命盘恰有禄、权、科、忌四条四化事实；
- 每条事实恰好进入 4 个目标宫的三方四正组；
- 12 个目标宫合计产生 16 次事实引用；
- 每次引用必须精确绑定宫位、星曜、四化、关系、规则摘要和事实摘要；
- 十四主星可绑定既有落宫位置候选；辅／杂曜不得伪造主星位置主线；
- 某组无四化时显示明确空集合边界；
- 宫干飞化、自化、大限、流年、权重、借星、格局、吉凶和事件结果均不在本版本范围内。

默认测试盘 `1995-08-18 / 午时 / 男` 的命宫三方四正只命中一条：对宫迁移宫的紫微化科。页面显示“呈现与调和”候选，同时保留“被看见不等于评价有利、资格成立或行动充足”的反向约束。
