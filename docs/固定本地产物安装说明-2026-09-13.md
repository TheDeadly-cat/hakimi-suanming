# 固定本地产物的打包、安装和启动

日常入口固定为 `http://127.0.0.1:5188/`，使用 `c15ef05bb165`。开发源码的 5173、旧 4173 预览以及自动测试入口不是日常案例库。不要通过换端口或清理浏览器数据处理“案例不见了”。

## 安装者

在新 Windows 机器上先安装 Node.js 24.16.0；使用系统 PowerShell 5.1。此安装包只包含已锁定静态产物和仅依赖 Node 标准库的启动/核验程序，不要求项目 checkout、npm安装、Vite或原作者的用户目录。

将固定安装包解压到自己的目录，检查随交付提供的 ZIP SHA-256，然后在包目录运行：

```powershell
node --version
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-local-research.ps1
```

如 Node 不在 PATH，可加 `-NodeExecutable "D:\Runtime\node.exe"`。如需自选安装位置，可加 `-InstallRoot "D:\HakimiBaziWorkbench"`；具体包落在该目录的 `packages\c15ef05bb165` 中。参数不改变 5188 入口。

安装复制只创建新目录。目标已存在且内容完全相同时复用；不同时报错，不覆盖。失败的未完成目录留作诊断，不能被启动或当作已安装成功；请保留错误记录，由维护者确认后处理，不要删除日常浏览器资料。快捷方式创建前先验证安装后的完整清单；同名其他快捷方式不覆盖。

新快捷方式名为“哈基米八字研究台 (5188)”。用户已有的“哈基米八字研究台（本地自用）”和旧安装目录保持原样，新的打包/安装流程不改写它们。决定是否替换现用版本是后续独立动作，本包内容仍是同一 c15ef 固定产物。

## 启动与日志

安装后双击新快捷方式，或执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\launch-local-research.ps1 -PackageRoot "D:\HakimiBaziWorkbench\packages\c15ef05bb165"
```

启动先核对原锁、137个产物文件和完整安装包文件集合。现有5188服务返回完全相同首页和SW字节、且只监听127.0.0.1时复用；不匹配、超时或其他地址监听都停止，不选另一个端口、不终止服务。没有监听时仅启动包内的固定静态服务器，不运行build，不读取浏览器profile。

日志按每次运行单独存于 `%LOCALAPPDATA%\HakimiBaziWorkbench\local-launch-logs`，包括包验证、探测、服务输出及成功启动记录。`-NoBrowser -NoDialogs` 用于脚本诊断，避免打开日常浏览器；`-LogRoot` 可指定独立日志目录，但不能位于不可变安装包内部。

已安装包本身不写运行日志、案例或自动更新数据。个人案例仍由浏览器保存在同一个5188 origin下。备份导出、预检和恢复继续使用应用既有流程，由用户操作。
