## 4. 候选发现账

机器账精确保存四个 `uncontacted_public_candidate_lead`：Wendy Stacey、Geoff Gronlund、Bruce Scofield 和 Rhys Chatham。共有 11 条公开页面观察，按页面所有者折叠为 6 个上游组；每名候选观察到的去重组数依次为 `3 / 2 / 2 / 3`。

来源组数只用于防止把同一组织的多个页面重复计数。它不证明现实身份、资质、范围适配或候选之间的独立性。四名候选均保持：

六项待核范围为天文／时间／坐标、黄道／宫制／交点／相位、dignity／逆行／行运推进、解释／高风险、来源权利角色边界，以及不确定性／反例／弃权。任何公开 scope lead 都不能被改写为 `scopeVerified=true`。

四名候选形成六个两两组合；每一对保留十项独立性因素，当前 `assessmentState=not_started`、九项 `unknown`、另一席意见暴露项为 `not_applicable_before_review`。六对的 `pairwiseIndependenceEstablished` 和 `countsTowardExpertGate` 均为 false。

## 5. 角色分账

机器账固定三类不同职责：

- `western_domain_expert`：可审占星规则版本、解释和高风险边界；不能建立工程实现正确、来源权利法律结论或发布授权。
- `astronomy_engineering_reproducibility_reviewer`：可审时间尺度、参考系、星历、坐标、容差和可复现性；不能建立占星领域真值或解释权威。
- `source_rights_reviewer`：可审作品／版本／载体、许可证据和再分发事实；不能建立占星真值、法律裁定或发布授权。

工程 reviewer 和来源权利 reviewer 都不能占用未来两席 `western_domain_expert`。

## 6. 机械门与对抗结果

加载器对 ledger、basis 和三个上游使用 held-handle 端点读取；本地 JSON 的 hash 与 strict parse 来自同一 Buffer。它拒绝 duplicate key、BOM／非法 JSON、Proxy、accessor、对象 alias、cycle、异原型、稀疏数组、Symbol 和 `-0`；自己的 `__proto__` 数据键不会改变输出原型。候选门自己的 Array／Object／String／Reflect／Set／WeakSet／Hash 原语在模块加载时固定，pure verifier 的 post-import 原型和 iterator poisoning 负例通过。成功结果递归冻结，并且只有完整固定加载后才获得私有 WeakSet brand。

自重算摘要仍不能晋级 authority、reviewer seat、scope、independence、expert opinion、expert gate 或 Binding，也不能注入私人联络、页面正文、exact quote、formal packet／registry backlink。CLI 不接受 caller 参数或 `NODE_OPTIONS`，并只返回校准后的零状态。
