# 八字内容 v0.13：主题索引与证据钻取

日期：2026-08-12
状态：当前源码的只读主题索引、筛选与页内锚点已实现并通过定向工程门；主题排名、专家裁决、总体吉凶与事件结果仍未签发

## 1. 本轮问题与结果

v0.12 已经在排盘后给出固定四步首读，但完整解读仍是一张较长页面：用户可以看到旺衰、四柱十神、全部透藏出现项、神煞入口和来源，却缺少一个从首读快速钻到对应证据的目录。

本轮新增 `hakimi.bazi.theme_index_review/0.1.0`：

- 固定提供年柱、月柱、日柱、时柱、神煞入口五张导航卡；
- 每张柱位卡直接复用 10×4 审稿表的结构化 `focus`、已有透干/藏干出现项和六场景十神敏感性；
- 提供“全部 / 年柱 / 月柱 / 日柱 / 时柱 / 神煞”页面内临时筛选；
- 提供旺衰因素账、四柱十神卡和神煞显式入口的真实页内锚点；
- 神煞索引只跳转，不会预先运行、计数或解释神煞；
- 卡片顺序、筛选状态和出现次数不转换为排名、分数、第一主题或吉凶。

### 2.2 页面导航与控件语义

[W3C WAI-ARIA Button Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/)说明二态切换按钮应通过 `aria-pressed` 暴露状态；本轮六个筛选按钮保持标签不变，并准确更新 `aria-pressed`。

[W3C WAI 页内导航教程](https://www.w3.org/WAI/tutorials/page-structure/in-page-navigation/)提出长页面可以使用导航 landmark、目录与标题锚点帮助定位。本轮据此使用带可访问名称的 `nav` 和真实 `href="#..."`。该页面自身标记为尚未正式批准的草案，因此只作为界面语义参考，不作为命理或发布真值。

## 3. 实现契约

核心文件：

- `packages/bazi-interpretation/src/theme-index-review.ts`
- `packages/bazi-interpretation/src/index.ts`
- `apps/web/src/components/bazi-interpretation-panel.tsx`
- `apps/web/src/styles.css`

投影固定声明：

- `filterPolicy: temporary_client_side_visibility_only`；
- `orderingPolicy: fixed_pillar_order_not_ranked`；
- `mutationPolicy: read_only_projection`；
- `shenshaPolicy: explicit_gate_only_not_calculated`；
- `selectedPrimaryTheme: null`；
- `expertThemeVerdict: null`；
- `ranking: null`；
- `overallGoodBad: null`；
- `result: null`。

每张导航卡还固定保留 `rank:null`、`score:null`、`expertTruthClaimed:false` 和 `scoringAllowed:false`。时辰不可靠时，时柱卡降为 `partial`、出现项为 0，不补猜时柱。来源、现有投影、柱位干支、时辰可靠性或 10×4 焦点映射不一致时 fail closed。

筛选状态只存在于 React 组件内存；不写入 Case、Revision、规则快照、IndexedDB 或 mutation epoch。页内锚点也只改变 URL hash 和滚动位置。

## 7. 尚未成立的结论

- 固定五入口不是人生领域或命理重要性排名；
- 出现次数不是力量、权重、主轴或吉凶分；
- 主题筛选不是专家选择的“全盘第一主题”；
- 神煞入口不表示已经命中、解释或裁决任何神煞；
- 主题索引不签发用神、格局、调候、喜忌、运限或具体事件；
- 工程测试、浏览器交互、截图和哈希不构成专家真值。
