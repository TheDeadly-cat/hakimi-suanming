# 八字内容 v0.9：神煞命中按柱直读与证据

日期：2026-08-12

状态：Web v1 在用户主动打开神煞研究预览后，可按年、月、日、时柱逐项查看现有五条神煞候选的命中事实与位置议题；正式神煞层仍关闭，神煞方向、综合喜忌、事件结果与最终结果均固定为 `null`

## 1. 本轮结论

v0.5 已经具备五条神煞取法事实、5×4 位置议题候选和按神煞名称排列的研究预览。因此，本轮没有另造神煞算法，也没有重写已有 20 条内容，而是关闭一个阅读路径缺口：用户希望在命盘的相关年/月/日/时位置直接看到“这里命中了什么、为什么命中、可能讨论什么”。

本轮新增 `hakimi.bazi.shensha_occurrence_review/0.1.0` 只读投影，把现有 `ShenshaResearchResult` 无损重排为四个柱位组。每个命中出现项保留：

- 年柱、月柱、日柱或时柱及对应干支；
- 神煞名称、命中的地支；
- 取法基准、基准值与候选目标支；
- 一句可核对的命中陈述；
- 对应的 5×4 原创位置议题、可用表达、待复核张力与合参门；
- 原注册表来源定位、来源 ID 和编辑内容 ID；
- `interpretation:null`；
- `shenshaOrientation:null`；
- `overallGoodBad:null`；
- `eventOutcome:null`；
- `result:null`；
- `expertTruthClaimed:false`；
- `scoringAllowed:false`。

固定演示盘 `乙亥 / 甲申 / 辛巳 / 壬辰` 的新按柱索引显示：

- 年柱：当前五条候选 0 项；
- 月柱：天乙贵人 1 项，以年干乙取子、申，月支申命中；
- 日柱：驿马 1 项，以年支亥取巳，日支巳命中；
- 时柱：当前五条候选 0 项。

零项只表示“当前五条年干/年支基准候选没有命中本柱”，不表示不存在其他流派、其他神煞或其他取法。同一神煞如果落在多柱，会按柱保留多个出现项，不合并成次数分数，也不据数量判断吉凶。

## 4. 协议与代码变更

### 4.1 按柱出现项协议

`packages/bazi-interpretation/src/shensha-occurrence-review.ts`

- 版本：`hakimi.bazi.shensha_occurrence_review/0.1.0`；
- 范围：`registered_hit_occurrences_grouped_by_pillar`；
- 证据类：`derived_read_only_projection`；
- 正式层：`formalLayerActivated:false`；
- 输出固定为四个柱位组和逐项命中事实；

- 命盘地支、实际命中支、位置数组、位置标签、编辑候选必须逐项对齐；
- 命中规则、基准、目标支、来源 ID、来源定位、审阅状态或空解释被改写时，失败关闭；
- 全盘内容 ID 重复时失败关闭；
- 函数不修改输入命盘事实或原神煞研究结果。

`packages/bazi-interpretation/src/index.ts`

- 导出按柱协议、类型、Profile 与构建函数；
