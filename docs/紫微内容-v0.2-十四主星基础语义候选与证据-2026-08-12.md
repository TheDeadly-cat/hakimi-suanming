# 紫微内容 v0.2：十四主星基础语义候选与证据（2026-08-12）

## 1. 本轮结果

在 4218 紫微隔离工作台已有“三方四正事实摘要”上，新增完整十四主星的版本化基础语义候选：

1. 注册表恰好覆盖紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军。
2. 每条内容绑定冻结 `starId`，包含三个中性主题、一段白话观察方向、一段“需合参”提示和两层来源定位。
3. 用户选择任一宫位后，四张三方四正卡会在已验真的盘面事实下直接展示命中主星的候选短解；双主星宫显示两条，空主星宫不臆造内容。
4. 每条卡明确显示“待专家复核”，页脚明确禁止单星吉凶、人格标签、组合断语、运限结论与评分。
5. 主星 ID 缺登记或冻结中文名不一致时投影失败关闭；辅／杂曜的 `candidateContent` 必须为 `null`。

这一步完成的是“排盘后先能读懂主星在该宫可能强调什么”的内容底座，不是最终直断，也不是紫微专家验收。

## 2. 内容版本与字段边界

- 内容版本：`ziwei.major_star.neutral_candidate/0.1`
- 内容类型：`neutral_base_semantics_candidate`
- 审稿状态：`awaiting_expert_review`
- 发布状态：`isolated_candidate_only`
- 固定声明：`expertTruthClaimed:false`
- 固定声明：`directOutcomeAllowed:false`
- 固定声明：`scoringAllowed:false`

这些字段位于主线程只读显示投影，不进入上游计算 Worker 的事实结果，不写回 Browser 工件、Revision 或 IndexedDB，也没有 mutation epoch 旁路。

- [《紫微斗数全书》总页](https://zh.wikisource.org/zh-hans/紫微斗數全書)将卷一“诸星问答论”依次列出十四主星篇目；页面将清朝作品标为公有领域。

现代资料仍是二手研习材料，并非本项目专家签章或跨流派共识。

## 5. 代码与失败关闭边界

### 5.1 注册表门

模块初始化时要求：

- 条目数量恰为 14；`starId` 与 `contentId` 均唯一；
- 每条恰有三个不重复主题；
- 两个来源引用都必须命中已登记来源；
- 候选短句不得包含“你、一定、必然、注定、保证、终身、大吉、大凶”等绝对化或个人标签措辞。

### 5.2 投影门

- 只有 `category:"major"` 才能查候选注册表。
- 主星缺条目或 `starId` 对应中文标签不一致会抛错，不显示半套内容。
- `minor / auxiliary` 固定得到 `candidateContent:null`。
- 来源注册表随投影提供；UI 找不到引用来源时停止渲染该结果。

### 5.3 保存边界

- 候选内容没有新增数据库字段、Store、写事务或 mutation epoch 例外。
- 手工 Browser QA 只计算、切换宫位和查看，没有点击保存；本地 Revision 数保持 0。
- Edge 自动门沿原正式交互执行保存、跨标签刷新和唯一清空；它走既有 epoch 比较与事务链，没有直接改 IndexedDB。
