## 本段完成了什么

本段新增一个单向 child，只证明四个项目自写、无人物身份的固定 probe 可以重复执行并得到确定的诊断拒绝：

1. 缺少固定根字段 `civil_calendar_and_date`；
2. 星历摘要只有 63 位，违反草案中的 64 位小写十六进制形状；
3. 候选自身声明 `classification=gap` 与 `rejection_code=nonexistent_local_wall_time`；
4. 候选符合当前 draft schema 的字段形状，但 input contract 尚未 admitted。

四条路径分别得到：

- `SCHEMA_REQUIRED_PROPERTY_MISSING`
- `SCHEMA_PATTERN_MISMATCH`
- `DECLARED_DST_GAP_REJECTED`
- `INPUT_CONTRACT_NOT_ADMITTED`

所有返回值都是 `structural_precheck_diagnostic_rejection_receipt`。它们不计为产品输入实例，不计为产品 input rejection receipt，不计入 admission，也不产生 acceptance、normalization、time-resolution、fact、rule 或 success artifact。
