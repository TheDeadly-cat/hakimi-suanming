# 阶段 D：非技术专家两席试填差异并列候选 v1（2026-09-03）

## 结论

本轮补齐了无代码专家 pilot 的一个实际缺口：A、B 两份完整试填回件返回后，协调人可以在隔离本机页面中重新预检同一 review cycle、各自外部 manifest pin 和完整回件，再把两席的自述范围、五个合成场景和四个总体问题逐字段并列。

该结果只是 synthetic pilot private comparison candidate。它不选择赢家、不投票、不平均、不自动合并，不产生正式 disagreement inventory 或 reconciliation record，不允许 pilot→formal 转换，也不增加 formal 2/2 或专家门计数。

固定发布治理保持：

```text
releaseIdentity = legacy-v13
targetSchema = 13
migrationId = null
publicDeploymentAuthorized = false
expertClaimsAuthorized = false
```

## 审查后修正

独立审查发现并已修正：

1. 清除操作与异步比较之间的迟到回填竞态：增加 operation generation，迟到成功或错误不得重新进入 DOM。
2. 超大文件会在 5 MiB 上限前完整读入：现在先检查 `File.size`，再调用 `arrayBuffer()`。
3. 运行中修改 pin、cycle 或文件会形成混合快照：现在开始时同步捕获全部绑定，并在运行期间禁用五个输入。
4. 成功后修改任一绑定仍显示旧结果：现在任何 input/change 都立即撤下旧结果，必须重新比较。
5. 固定端口与普通 profile 无法排除历史 Service Worker：CLI 改为随机端口，同时把当前授权范围降为 synthetic fixture only。
6. comparison 可能被误称为正式 reconciliation：改为 `manualPilotFollowup*`，并显式固定 formal disagreement/reconciliation 全部 false。
7. 新 pilot 类型未进入 formal deny inventory：已补入十类 pilot record type 闭集。
8. 展示用数组会格式化，不能称为原始字节：页面改称“字段显示值”；原始完整回件仍保持不覆盖。

## 仍未证明、不得外推

当前 pair viewer 明确固定：

```text
syntheticFixtureOnly = true
realReturnLoadingAuthorized = false
browserProfileIsolationEstablished = false
preexistingServiceWorkerExcluded = false
browserExtensionInterceptionExcluded = false
actualHumanParticipationEstablished = false
actualHumanIndependenceEstablished = false
expertIdentityEstablished = false
opinionAuthenticityEstablished = false
externalAiUseExcluded = false
expertVsAiAccuracyEvaluated = false
predictiveAccuracyEvaluated = false
formalAdmissionAllowed = false
safeToPublish = false
```

因此：

- 当前页面只能处理程序生成的合成回件；不得载入真实专家回件。
- 两席自述“未看另一席”不证明现实独立，无法排除协调人口头泄露或两人私下交流。
- 摘要、pin 和 process-local brand 都不是数字签名、身份、可信时间、first-seen 或 custody 证明。
- 机械比较不能判断意见来自真人还是外部 AI，也不能证明专家资格或内容正确。
- 两席字段相同只表示规范字段值相同，不等于专家真值、命理有效性或预测准确度。
- 浏览器和 Node 定向测试不代表完整应用、全仓 typecheck、默认 Web build、正式 PWA/SW、公开主机、发布或回滚已经通过。
