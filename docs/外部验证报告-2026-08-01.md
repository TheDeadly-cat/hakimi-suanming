# 哈基米命理：外部验证报告

> 调研日期：2026-08-01  
> 范围：竞争产品、网页与手机跨端技术、中国大陆上线初筛  
> 说明：竞争与技术判断用于产品决策；合规部分仅为前期风险识别，不构成法律意见。
> 后续决策：已确定 B 海外中文命理解读版先行，A 以独立 A0 文化版推进。文中的“先选首发地区”保留为调研过程；当前待选的是 B 的第一个具体海外地区。详见 [产品决策记录](./产品决策记录-2026-08-01.md)。

## 1. 执行摘要

### 已验证的市场机会

现有产品大致分为三类：

1. 专业排盘工具的计算和资料能力强，但普通用户较难读懂；
2. 新一代 AI 命理产品更易读，但计算、规则判断与 AI 自由表达之间的边界往往不够透明；
3. 星座、情感与社区平台留存机制成熟，但内容审核、真人供给和社区运营成本高。

因此，项目真正可建立的差异不是“术数比别人更多”，而是：

- **可解释**：区分确定性排盘、规则解释和 AI 表达；
- **可纠正**：出生时间不确定时诚实降级，不伪装精准；
- **新手可读**：术语可以展开，解释“是什么、为什么、有哪些流派差异”；
- **持续有用**：从静态长报告延伸到问题追问、阶段复盘和个人记录；
- **跨端一致**：网页、未来 App 或小程序共用账号、命盘和权益；
- **安全可信**：不恐吓、不代替专业决定，数据可查看、导出和删除。

### 改变路线的关键风险

如果面向中国大陆公众提供“AI 算命、运势预测、付费占卜”，存在实质性下线风险。国家网信办曾通报“天天吉历”因提供有偿算命、占卜服务，被责令下线相关版块、退款并限期关闭；2024 年“清朗”行动继续明确整治网上算命占卜付费服务。[天天吉历执法通报](https://www.cac.gov.cn/2023-12/29/c_1705519843935413.htm) · [2024 年春节网络环境整治通知](https://www.cac.gov.cn/2024-01/29/c_1708196062197841.htm)

这意味着“仅供娱乐”免责声明不能代替产品实质调整。首发地区必须成为立项前的第一项决策。

### 当前推荐

- **产品验证渠道**：响应式 Web/PWA；
- **技术演进**：验证后再用 Capacitor 增加原生能力；
- **内容核心**：八字历法与确定性排盘模块，但与 AI 表达严格分层；
- **大陆候选定位**：18+ 的传统历法文化学习与非预测性自我探索，先做法律和属地预审；
- **境外候选定位**：面向海外中文用户的现代命理解读与 AI 陪伴，按目标市场法律和商店规则复核；
- **不建议**：首版同时做大陆和海外两套产品、同时上 Web/App/小程序、同时覆盖多种术数。

### 2.2 事实与推断分离

**事实：** 代表产品普遍采用免费排盘、单次报告、AI 对话额度、订阅或真人咨询中的一种或多种模式；多家产品已覆盖网页与原生 App。

**推断：** 用户不缺一个“能排盘”的产品，项目更可能凭以下组合形成差异：

```text
专业计算可信度
  × 新手第一次就看懂
  × AI 能解释依据
  × 后续能围绕真实问题持续交流
  × 所有终端账号与权益一致
```

**反方证据：** 专业工具已经积累口碑，大众平台已有大量内容和用户。新产品如果只有“接入一个大模型生成长报告”，很难构成壁垒。

## 3. 跨端技术验证

### 3.1 推荐：PWA 首发，Capacitor 后置

[Capacitor 官方文档](https://capacitorjs.com/docs)支持把现代 Web 项目扩展到 iOS 和 Android；PWA 本身保留普通 URL 的搜索、分享和安装能力。[Capacitor PWA 文档](https://capacitorjs.com/docs/web/progressive-web-apps)

这条路线适合当前产品，因为报告是文字密集、可分享、可能依赖搜索获客的内容，且首版尚未证明原生推送和应用内购买是必要能力。

限制也应提前承认：

- Apple 不接受只有 WebView 套壳、缺少独立价值的 App；其审核指南还把 `fortune telling` 列为高度饱和类别，新 App 需要体现有意义的差异。[Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)
- Capacitor 的 Android 推送默认依赖 FCM，面向大陆 Android 仍需华为、小米、OPPO、vivo 等厂商通道或聚合服务。[Capacitor Push Notifications](https://capacitorjs.com/docs/apis/push-notifications)
- iPhone/iPad 的 PWA Web Push 需要先添加到主屏幕，再由用户主动授权。[WebKit Web Push 说明](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)

### 3.2 备选路线

| 路线 | 适用条件 | 不作为当前首选的原因 |
| --- | --- | --- |
| React Native / Expo Web | 第一版必须进入商店且原生体验优先 | Web 与原生仍会有分支；没有微信小程序目标；大陆 Android 推送仍需适配 |
| Flutter Web + Mobile | 高交互可视化和原生 App 远重于内容网页 | Flutter 官方说明 Web 不适合大量静态、文字密集内容；另需 Dart 技术栈。[Flutter Web FAQ](https://docs.flutter.dev/platform-integration/web/faq) |
| uni-app | 微信小程序已确认审核可行且是核心渠道 | 平台条件分支和多端 QA 会增长；技术能编译不代表内容能通过审核 |

微信小程序不是默认的安全首发渠道。现行平台规范禁止宣扬封建迷信，并对虚拟商品、订阅内容和付费功能规定专门支付规则。[微信小程序平台运营规范](https://developers.weixin.qq.com/miniprogram/product/)

### 3.3 推荐架构

```text
响应式 Web / PWA（首发）
Capacitor iOS / Android（验证后）
小程序客户端（仅在审核可行后）
              │
              ▼
        统一 API 与账号
              │
     ┌────────┼────────┐
  历法排盘   报告/AI   订单与权益
              │
              ▼
        渠道支付与推送适配
```

设计原则是共用后台、领域模型、账号和权益，不追求所有渠道 100% 共用 UI。

## 4. 中国大陆上线初筛

### 4.1 内容定位：立项级风险

《网络信息内容生态治理规定》第六条禁止制作、复制、发布宣扬邪教和封建迷信的网络信息。[规定原文](https://www.cac.gov.cn/2019-12/20/c_1578375159509309.htm)

结合已有执法案例，大陆版本不应以下列内容为核心功能或付费卖点：

- 预测未来、改命转运、消灾化劫、破太岁；
- 对疾病、死亡、婚变、怀孕、灾祸、发财、升职或投资结果作确定性断言；
- 先制造“有灾”恐惧，再付费解锁答案或化解服务；
- 售卖符咒、法事、开运物或保证效果的服务；
- 根据命理输出劝用户停止治疗、投资、离婚或辞职。

广告中也不得含有迷信内容或无法证实的效果承诺。[中华人民共和国广告法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)

### 4.2 大陆候选定位仍需预审

更可行但尚不能保证可上线的候选模式是：

- 18+ 的传统历法文化学习；
- 展示干支、节气、历法等确定性计算和有出处的文化知识；
- AI 只解释知识、提出开放式反思问题；
- 用户自主设定目标、写日记和做阶段复盘；
- 不声称系统能预测或改变真实命运。

八字排盘、流年和合盘即使包装成文化体验，仍可能因产品实质被认定为网上算命。必须在开发付费功能前，把页面原型、典型输出与营销材料交由大陆执业律师和属地主管部门复核。

### 4.3 未成年人

《未成年人网络保护条例》禁止向未成年人传播含有迷信等危害其身心健康的信息；不满 14 周岁儿童的个人信息处理还适用更严格规则。[未成年人网络保护条例](https://xzfg.moj.gov.cn/front/law/detail?LawID=1694) · [儿童个人信息网络保护规定](https://www.cac.gov.cn/2019-08/23/c_1124913903.htm)

首版建议明确不面向未成年人，不收集儿童出生档案，也不向其提供个性化营销或付费功能。

### 4.4 生成式 AI 服务与内容标识

面向境内公众提供 AI 文本解释，需要按《生成式人工智能服务管理暂行办法》建立适用人群说明、输入输出保护、投诉举报和违法内容处置机制。[暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)

官方备案公告说明：调用已备案模型 API 的应用或功能，由地方网信部门开展登记；应用上线后应公示使用的模型名称及备案号或上线编号。[2026 年 3—4 月生成式 AI 服务备案公告](https://www.cac.gov.cn/2026-05/13/c_1780413225190669.htm)

《人工智能生成合成内容标识办法》及强制性国家标准 GB 45438-2025 要求对 AI 生成的文本、图片等进行显式和隐式标识；分享图和报告导出也应保留标识。[标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm) · [GB 45438-2025 官方标准页](https://std.samr.gov.cn/gb/search/gbDetailed?id=301E0388CB75788DE06397BE0A0AE1B4)

工程上应做到：

- 每条 AI 解读附近显示“AI 生成内容”；
- 分享图、PDF 和报告将标识直接渲染进内容，并按标准写入元数据；
- 用户协议说明标识方式；
- 不提供“去除 AI 标识”选项。

### 4.5 个人信息与数据最小化

出生日期、时间、地点、性别、手机号与对话一旦关联到可识别自然人，至少构成个人信息；自由对话还可能包含健康、金融账户等敏感个人信息。[中华人民共和国个人信息保护法](https://sdca.miit.gov.cn/zwgk/fgbz/art/2026/art_3e2ad39014b743d58bab7a6815640aee.html)

建议：

- 游客可以完成基础体验，不强制手机号；
- 排盘尽量在浏览器或独立计算服务完成；
- 模型只接收去身份化后的结构化结果，不接收姓名、手机号和原始出生地点；
- 用城市选择器完成时区计算，不申请 GPS；
- 原始出生资料与账号分开加密存储；
- 默认不用于模型训练、广告画像或营销；
- 支持查看、更正、导出和一键删除；
- 合盘不要求真实姓名，录入他人信息前确认已获授权。

官方的必要个人信息范围规则把星座性格测试类实用工具列为无需个人信息即可使用基本功能的类型，因此不应把手机号、通讯录或定位作为基础体验前置条件。[常见类型移动互联网应用程序必要个人信息范围规定](https://www.cac.gov.cn/2021-03/22/c_1617990997054277.htm)

### 4.6 备案、支付与渠道

- 境内网站需根据业务性质办理 ICP 备案或许可；付费信息服务是否涉及增值电信许可，应在收费前专项确认。[互联网信息服务管理办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_483f0dd8eb1b4dc5961e4e008bd4a083.html)
- 境内原生 App、小程序和快应用需履行 APP 备案。[工信部 APP 备案通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)
- 自动续费需要显著提醒并提供简便取消入口。[消费者权益保护法实施条例](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2024/art_0aea188276a44f0baf940ab95ee00e0a.html)
- iOS 内解锁数字报告、会员与功能通常适用 Apple 应用内购买规则，需按提交时的店面规范复核。[Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)

## 5. 产品路线选择

### 路线 A：中国大陆优先

**候选名称：** 哈基米人生地图 / 哈基米东方生活志。  
**产品实质：** 历法文化学习、知识解释、日记与开放式自我反思。  
**暂不进入：** 吉凶断言、运势预测、付费命书、改运与真人占卜。  
**变现候选：** 文化课程、阅读与记录工具、非预测性的自我复盘功能；任何收费模式先经实质审查。  
**发布门槛：** 页面、输出样例、广告、数据与 AI 登记路径完成法律和属地预审。

优点是服务大陆用户；缺点是与最初“算命 App”的商业想法距离较大，且即使转型也不能保证审核通过。

### 路线 B：海外中文用户优先

**候选名称：** 哈基米命理 / Hakimi Life Map。  
**产品实质：** 八字排盘、解释、专题报告、AI 追问与阶段复盘。  
**变现候选：** 单次专题报告、短周期问答权益、后续会员。  
**渠道：** 全球 Web/PWA 先行，再按用户分布决定 App Store 与 Google Play。  
**发布门槛：** 针对注册主体、服务器、用户所在地、支付和商店逐地复核隐私、消费者保护及内容规则。

优点是更接近最初产品愿景；缺点是支付、获客、客服与多地区合规更复杂。

### 路线 C：大陆与海外双版本

共用历法引擎、账号与基础领域模型，内容、功能、支付和运营完全分区。

这不是 MVP 推荐路线：它会立刻引入双套内容策略、地区识别、数据存储、支付、发布与合规流程，也增加误放功能到错误地区的风险。

## 6. 建议决策顺序

1. 为已经确定先行的 B 路线选择首个具体海外地区；
2. 再确定产品实质：文化自我探索还是个性化命理解读；
3. 再确定首批目标用户与首个问题场景；
4. 用可点击原型和 40 条典型 AI 输出做用户与合规验证；
5. 验证通过后才进入完整排盘、账号、支付和原生渠道开发。

## 7. 大陆版发布阻断清单

出现任一项，不进入付费或上架：

- 产品仍以算命、占卜、运势预测、改命转运为实际核心；
- 含疾病、死亡、婚姻、财富或投资的确定性断言；
- 面向未成年人提供命理解读或自动化营销；
- 未确认 ICP/APP/AI 应用登记与可能涉及的算法、安全评估路径；
- 未按现行标准实现 AI 显式与隐式标识；
- 原始出生资料或对话未经专项评估即发送境外；
- 隐私政策未列明模型、SDK、处理目的、保存期限与删除渠道；
- 自动续费默认开启或取消困难；
- 广告含改命、消灾、保证准确等表达；
- 没有内容审核、投诉举报、危机处理、数据泄露与退款机制。

## 8. 下一步建议

在写完整产品之前，先完成两件事：
