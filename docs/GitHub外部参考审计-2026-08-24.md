## 本轮实际落地

新增的八字 `Interpretation Evidence Envelope` 是现有旺衰证据叙事的只读投影，当前只服务于已存在的八字工程候选层：

- 绑定当前 Revision、`resultHash`、facts projection digest、规则配置 digest、引擎/上游版本和 tzdb 版本；
- 显式记录历法、时间精度、地点精度、IANA 时区、DST、真太阳时、历法边界、闰月、时柱纳入和规则审定状态；
- 分开输出 facts、rules、source bindings、interpreted claims 和 stability；
- `supported` 只表示当前工程投影的引用链闭合，不表示术数、专家或科学真值；
- 未核实来源定位或被阻断规则对应的叙事保持 `blocked / withheld`；
- 不复制原始出生日期、出生时刻、地点标签、坐标或备注；未知时辰不得纳入时柱；
- 仍把 Revision ID、时区和派生命盘事实标记为敏感数据；“未复制原始输入”不等于匿名或允许联网传输；
- 当前只声明“规则候选扰动”覆盖，出生时间、DST、节气边界扰动仍是 `not_assessed`；
- builder 先重算 Revision 完整性摘要；Envelope 自带 payload SHA-256，但不声称签名或真实性；公开 validator 还必须拿原始 Revision 和派生输入重建逐字段比对，不能靠“有效 ID”洗白篡改文本或换绑引用；
- 网络传输及其授权、持久化写入、命盘变更、正式激活和公开发布授权全部保持关闭。

在 Envelope 之上还新增了隔离的确定性 AI 忠实性检查：

- AI 草稿只能使用封闭 assertion grammar，并绑定当前 verified Envelope 的 payload SHA-256；
- `fact_quote`、`canonical_claim_quote` 和 `rule_quote` 只有逐字匹配规范内容才可见；规则和边界文本最多以 caveat 展示；
- 未知 ID、事实值不符、开放式改写、blocked 内容，以及吉凶、用神、事件结果、专家真值或科学有效性 family 全部 withheld；
- 不把自由文本送给模型二次自评，也不在验证结果中回显未经验证的自由文本；
- 空草稿或没有机器可核断言时，coverage/faithfulness 比率为 `null`，不会产生伪 100%；重复语义键直接拒绝，不能刷分；
- `supported` 仍只表示“逐字忠实于当前工程 Envelope”，不表示解读质量或内容真值。

同时新增了独立的出生民用时间扰动稳定性报告：

- 只接受公历且精确到分或秒的冻结 Revision，先要求 `offset=0` 通过完整描述符匹配的注册复演执行器与绑定 tzdb；基线不一致就不计算其他偏移；
- 固定按 `0/-1/+1/-5/+5/-15/+15` 分钟评估，`0` 是首个执行门；偏移的是 Gregorian 民用墙上时间，不是 UTC 瞬时点；
- 报告明确分开 `requestedOffsetsMinutes`、实际 `calculatedOffsetsMinutes` 与携带 block code/时区状态的 `blockedOffsets`，blocked 样本不会再被称为“已评估”；
- 只比较版本化的完整四柱事实投影，不比较必然随输入变化的 `resultHash` 或包含原始 `solarText` 的完整 facts；
- 分开记录柱身份变化、完整柱事实变化和严格白名单字段路径，但不输出原始出生日期、时刻、地点、坐标、备注或源时区；
- 每个 calculated 场景记录 `resolved_unique / resolved_overlap_earlier / resolved_overlap_later` 及实际选择；kind、status、choice 和 policy 必须一致；固定 earlier/later 分别有回归用例；
- `require_user` 的任一非零 DST 重叠/空档样本都失败关闭；不会把源样本的 earlier/later 选择扩张为其他墙上时刻的授权，测试会核对所有实际落入 overlap 的非零偏移集合；
- 每个已计算或已探针场景都要求 `solarTimeApplied === false`；精确到秒的平移通过“偏移后恰落立春当秒”的边界用例证明没有截断秒；
- 只要有样本 blocked，总评就是 `inconclusive_due_to_blocked_offsets`；全部样本可算后才区分 `pillar_projection_unchanged_for_all_requested_offsets` 与 `pillar_projection_changed_within_requested_offsets`；
- 结论只覆盖固定偏移下的派生命盘投影，不声称真实出生时间、解释稳定性、专家真值或科学有效性。

历史 0.4.0 确定时刻排盘 kernel 已从现行 `calculateChartForBundledSnapshot` 物理分离，但证据范围仍严格限定为 `source-locked current-build replay`：

- `executorId`、六字段 engine descriptor、registry 外形、精确 lookup 和无 fallback 语义不变；现行普通计算入口未改，旧 Revision、manifest、resultHash 和 tzdb snapshotId 均未重签；
- 版本化模块内字面量冻结 schema `1.0.0`、hash schema `2.0.0`、hash-v2 payload 投影和活动 2026c snapshotId，避免这些 current 常量升级时静默改变 0.4.0 输出；
