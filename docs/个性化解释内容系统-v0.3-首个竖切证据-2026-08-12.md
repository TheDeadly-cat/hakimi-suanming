# 个性化解释内容系统 v0.3：首个竖切证据

> 日期：2026-08-12  
> 范围：八字 Web v1 的旺衰候选与十神柱位解释  
> 结论：工程竖切已实现并通过定向测试、类型检查、默认构建和真实桌面浏览器流程；**没有取得命理专家真值，也没有开放神煞、紫微或西洋正式入口**。

## 1. 历史证据（仅作基线，不算本轮新证明）

- 当前工程已能生成并保存四柱、透干十神、藏干十神及其字段来源。
- 默认发布身份在本轮开始前为 `legacy-v13 / targetSchema 13`。
- 紫微 4218、西洋 4219 仍为隔离草案；既有浏览器门不等于解释内容已获专家认可。
- 既有 Schema 15/16 工程候选、容量门和跨 Schema 测试不证明本轮旺衰或十神文案正确。

## 2. 本轮新增实现

### 2.1 纯函数规则候选

新增 `@hakimi/bazi-interpretation`：

- 输入仅为当前修订的 `ChartFacts` 和“时柱是否可靠”选项。
- 无数据库写入，不读写 IndexedDB，不接触 mutation epoch / CAS。
- 输出规则包 ID、版本、流派、审阅状态、来源、旺衰因素账、五档结果、四柱十神解释和已知缺口。
- 未知时辰或仅日期输入会把时柱从旺衰权重和位置断语中排除。

0.1.0 的透明候选权重为：

| 因素 | 权重 | 说明 |
|---|---:|---|
| 月令主气 | 4 | 单列月令；当前为最高权重 |
| 年/月/时透干 | 2 | 日干是参照点，不把“日主”当十神解释 |
| 每支主气藏干 | 2 | 月支主气会同时进入“月令”和“支中作用”；此双计设计须由专家裁决 |
| 其余藏干 | 1 | 每项分别进入因素账 |

分侧规则：印、比劫进入支持侧；食伤、财、官杀分别进入泄、耗、克侧。支持占总权重比例：

- `< 0.25`：很弱
- `0.25—<0.43`：偏弱
- `0.43—0.57`：相对中和
- `>0.57—0.75`：偏强
- `>0.75`：很强

这些阈值是可审计的工程候选，不是古籍直接给出的统一算法，也不是专家真值。

### 2.2 Web 呈现

- 默认“结构”页顶部直接显示“本盘解读已生成”：旺衰候选、支持/泄耗克摘要和年/月/日/时四柱十神。
- “概览”页显示完整因素账、四张十神位置卡、相对旺衰的“偏有利 / 需警惕 / 条件性”取向、来源与未关闭边界。
- 日柱卡使用日支主气十神，不把日干“日主”误当作十神断语。
- “偏有利 / 需警惕”被明确限定为相对当前旺衰候选的平衡方向，不是十神永久吉凶。
- 全部现代解释文字为原创编辑；竞品内容只用于信息架构研究，没有复制其文案。

### 2.3 来源与研究账

新增 `docs/个性化解释内容系统-v0.3-目标大纲与来源账-2026-08-12.md`，区分：

- 直接产品：易安居八字、LamjinLab、Ziwei Palace、紫微鉴。
- 邻近工具：iztro、Astro-Seek、Astro.com、Cafe Astrology。
- 原典/结构来源：中国哲学书电子化计划《滴天髓阐微》、维基文库《三命通会》与 iztro 三方四正文档。

易安居真实结果页实走观察到：内容覆盖很丰富，但同一演示结果中出现“日元偏弱”“旺相”“日主中和”等互相冲突的措辞，且事实、分数、古籍、现代断语和健康/化解内容混排。本项目只借鉴内容密度，不采用这种无逐条来源、无冲突状态的合并方式。

## 3. 本轮新验证

命令：


结果：`4` 个测试文件、`25/25` 通过。覆盖：

- 很弱 / 很强两端候选。
- 月令权重可见、输出确定且不修改输入。
- 旺衰变化会改变十神相对取向。
- 日柱使用支主气十神。
- 未知时辰排除时柱。
- 默认结构页摘要、完整概览、来源链接与专家边界。
- 字段依据面板继续只证明事实字段，并正确指向概览中的候选解释。
- 原有 ChartPage 定向回归。

命令：`npm run typecheck`  
结果：通过；隔离系统边界检查同时通过。

命令：`npm run build`  
结果：通过；Vite `2034` modules transformed。存在既有的大 chunk 警告，无新增构建错误。

### 3.3 真实桌面浏览器流程

在全新本地浏览器源上使用固定演示值 `1995-08-18 08:26，北京，男`：

1. 载入演示值。
2. 连续检查案例信息、出生资料、时间与规则。
3. 生成命盘并显式“保存并打开”。
4. 默认结构页立即出现解读摘要。
5. 进入概览查看完整因素账与四柱卡。

观察结果：

- 四柱：乙亥 / 甲申 / 辛巳 / 壬辰。
- 旺衰：`辛金 · 相对中和（候选）`。
- 因素账：支持侧 `11`，泄耗克侧 `14`。
- 四柱焦点：年柱偏财、月柱正财、日支正官、时柱伤官。
- 完整页显示规则 `0.1.0`、候选状态、来源与特殊格局等缺口。
- 首次视觉检查发现右侧字段依据面板打开时摘要按钮过窄；改为“两列主体 + 操作区独占下一行”后，在全新端口/新源复验，计算样式为两列、操作区 `grid-column: 1 / -1`，不再溢出。

这只构成真实桌面浏览器工程证据；没有 Android 设备、真机移动浏览器或命理专家验收。

## 4. 差异卫生

- 本轮开始时工作区约 `46` 条；本轮结束审计为 `56` 条。
- 新增/修改均局限于解释模块、Web 接入、配置/锁文件和两份新文档；没有清理、重置、覆盖或提交用户已有工作。

## 5. 仍未关闭的门

1. **专家门**：权重、阈值、月令主气双计、特殊格排除和 10×4 十神文案均需边界案例裁决。
2. **神煞门**：尚未建立逐项取法注册表，不得因用户要求内容丰富就静默开启。
3. **组合门**：合化、刑冲改变力量、格局、调候、用神、运限尚未进入本规则。
4. **移动门**：响应式 CSS 与组件测试已覆盖，但没有真机/固定移动设备证据。
5. **紫微/西洋门**：本轮只完成大纲和来源路由，仍保持隔离草案，不是正式产品功能。
6. **科学/专业建议边界**：传统术数解释不构成医学、法律、财务或确定性人生预测。
