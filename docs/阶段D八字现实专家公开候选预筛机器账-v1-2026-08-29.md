## 机械边界

ledger 与 basis 都使用只读 held handle、有界读取，并在打开前、打开后与读取后核对端点及目录链。最终文件 symlink、目录 symlink／junction、hardlink、非法 UTF-8、BOM、重复 JSON 键和未知字段失败关闭。ledger 的 SHA-256 与严格 JSON parse 复用同一个 Buffer；basis 的 SHA-256 与标记检查也复用同一个 Buffer。

这些逐文件检查不是跨文件原子快照，也没有 mutation epoch；不能排除 interval mutation 或 ABA。自摘要是字节自洽检查，不是数字签名、first-seen、custody 或真实性证明。

字段门会拒绝：

- 同一上游重复计数；
- 私有或联络字段注入；
- 登录或认证入口 URL；
- 页面正文或摘录字段；
- 对固定 `observationSummary` 目录值的任意改写，包括把联系信息、登录 URL、正文、backlink 或权威声明藏入合法字段；
- scope 晋级；
- 专家姓名字段或 reviewer seat 分配；
- 独立性关系伪造或配对晋级；
- identity／credential／expert／truth／release／auth 晋级；
- 正式包、manifest、registry backlink；
- 任何其他未知字段。

## 与正式专家包的隔离

本机器账没有被加入正式 packet、intake gap、manifest、system-admission registry、prebuild 或 release gate，也没有重签任何既有工件。
