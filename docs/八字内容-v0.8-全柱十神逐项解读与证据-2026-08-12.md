# 八字内容 v0.8：全柱十神逐项解读与证据

日期：2026-08-12

状态：Web v1 已能按柱展开全部透干、首位藏干与其余藏干十神出现项；重复十神保持为独立事实，不合并计分；综合喜忌与事件结果继续固定为 `null`

## 1. 本轮结论

本轮关闭了一个直接影响用户阅读完整性的缺口：v0.7 首屏每柱只完整解释一个焦点十神，其余藏干十神只有名称，不能满足“命盘含有什么十神、位于哪一柱、各自可能表达什么”的需求。

现在每柱都新增一个默认折叠的“查看本柱全部 N 项十神”入口，逐项保留：

- 透干十神；
- 地支首位藏干十神；
- 地支其余藏干十神；
- 同一十神在不同来源、不同位置的重复出现。

固定演示盘共显示 14 个出现项：年柱 3、月柱 4、日柱 3、时柱 4。其中包含 3 个非日主透干十神与 11 个藏干十神。日干本身属于“日主”，不伪装成十神出现项。

“首屏焦点”只是沿用既有快速阅读入口，不代表该十神必然最强。每个补充出现项都给出：

- 柱位、天干来源与十神名称；
- 对应的四柱位置议题候选文案；
- 继承自 v0.7 的中性扶抑方向：`可能补偏 / 可能增偏 / 条件性`；
- 当前旺衰账使用的因子 ID 与工程候选权重；
- 格局与救应、寒暖燥湿、合化与生克链、运限引动四道未评估复核门；
- `result:null`、`overallGoodBad:null`、`eventOutcome:null`。

因此，本轮能声明“用户可以逐项阅读命盘中实际出现的透干与藏干十神”，不能声明“所有藏干力量相同”“首位藏干必然最强”“工程权重已获古籍或专家验证”或“十神吉凶已经自动裁决”。

## 3. 定向在线研究与来源边界

本轮只把在线材料用于确认“哪些事实必须保留”与“哪些结论不能越界”，没有复制商业排盘网站的个案文案。

### 3.1 支持保留透干与藏干出现事实的来源

[《渊海子平》· 天干地支暗藏总诀与地支藏遁歌](https://ctext.org/wiki.pl?chapter=296619&if=gb&remap=gb)列出地支所藏天干。本项目据此把“透干”和“藏干”作为不同来源展示，并校验地支藏干数组与十神数组逐项对齐。

[《子平真诠评注》](https://ctext.org/wiki.pl?chapter=974137&if=gb)讨论杂气、透干、会支与藏干之间的组合条件。本项目据此保留同一十神的多个实际出现来源，不因名称重复就把它们折叠成一个计分结论。

[《滴天髓阐微》](https://ctext.org/wiki.pl?chapter=126492&if=gb&remap=gb)以天干、地支与支内人元为不同观察层次。本项目只借此支持“透干与支内藏干不可混成同一无来源事实”的显示边界。

中国哲学书电子化计划页面在本轮直接打开时返回 403，但搜索索引片段可用于发现相应章节；因此产品来源账只登记篇章与用途，不把本轮网络可访问性写成“全文逐字复核已完成”。

### 3.2 来源没有证明的内容

上述来源没有直接证明：

- 当前 0.1.0 月令、透干、藏干的工程权重；
- “首位藏干”的力量一定高于其余藏干；
- 同名十神出现次数可以直接相加为吉凶分数；
- 单轴身强弱足以决定完整用神、格局成败或具体事件；
- 本项目候选文案已经得到命理专家批准。

因此，协议只把第一项藏干命名为 `hidden_stem_main` 以表达数据表中的首位顺序，用户界面写作“首位藏干”，不写作“最强藏干”。工程权重公开显示为“旺衰账权重（工程候选）”，不冒充古籍权重或专家真值。

### 3.3 商业网站边界

用户提供的周易网站只作为“排盘后逐项解释”的产品形态参考。本轮没有复制其结果段落、规则表、页面结构、品牌表达或吉凶结论，也没有把第三方网站输出用作金标。

## 4. 协议与代码变更

### 4.1 全柱十神出现项协议

`packages/bazi-interpretation/src/ten-god-occurrence-review.ts`

- 版本：`hakimi.bazi.ten_god_occurrence_review/0.1.0`；
- 范围：`all_visible_and_hidden_ten_god_occurrences`；
- 证据类：`derived_read_only_projection`；
- 默认显示：四柱均可用时生成四组，但 Web 默认折叠；
- 来源枚举：`visible_stem / hidden_stem_main / hidden_stem_secondary`；
- 同名十神按内容 ID 分别保留，禁止自动合并计分；
- 找不到合法十神、事实与解释干支不一致、藏干数组与十神数组长度不一致或必需旺衰因子缺失时，直接失败关闭；

月支首位藏干会同时列出“藏干因子”与“月令因子”。演示盘因此可看到一项旺衰账权重合计 6；这只是对现有工程账的透明呈现，不是新增的命理力量裁决。

## 8. 尚未关闭的内容问题

以下仍需要用户与命理专家逐项裁决，不能靠当前工程测试自动回答：

1. 首位藏干与其余藏干在正式解释中的排序、权重和措辞应如何定义？
2. 透干、得令、得地、得势之间如何去重，避免把同一事实重复加权？
3. 同一十神在多柱、多来源重复出现时，哪些组合可以形成更高阶主题，哪些只能并列陈述？
4. 格局、调候、合化、生克先后与运限怎样反转单轴扶抑方向？
5. 每个十神在四柱位置的候选文案，哪些需要删改、增加反例或按性别/社会语境去偏见？
6. 哪些真实案例与时间记录可组成最小专家金标集，用来检验内容区分度而不是事后套话？

在这些问题关闭前，可以继续扩充“事实完整、来源可追、结论留空”的内容层；不能把出现次数、首位顺序或工程权重直接升级为吉凶、命运事件或专家真值。
