## 1. 结论

本阶段完成一份项目自写、clean-room、隔离的 JSON Schema 草案 `hakimi.vedic.rule-contract/0.1-draft`，以及只绑定该草案与既有 ADR／input／fact 闭包的 rule requirements child。草案只给出 `ruleDefinitionEnvelope`、`rulesetEnvelope` 与 opaque identity ref 的结构位，不含任何规则正文、来源正文、规则定义实例、规则实例、算法实现、求值器、版本化规则集或执行结果。

`ruleDefinitionEnvelope` 只要求规则身份、版本、digest、摘要、流派、适用条件、冲突、反例、来源绑定、事实依赖、权利、专家审阅、高风险、实现工件集与失败通道的引用位；`rulesetEnvelope` 只要求规则集身份、版本、digest、摘要、流派范围、规则定义集合、事实合同、来源绑定政策、权利、专家审阅、高风险、实现工件集与失败通道的引用位。冲突与反例列表可以为空；来源绑定与规则定义集合只在未来实例出现时要求非空。所有 digest 字段仍是 opaque ref，不在本层冻结规则 digest 算法或内容。

草案没有 `default`、`example(s)`、外部 `$ref`、传统原文、专家结论、工程权重、稳定性分数或格式化结果。D1、D9、D10、Vimshottari Dasha、Chara Karaka、Shadbala 与 Ashtakavarga 只作为 `excludedUnreviewedCandidateMethodIds` 中的未审候选 ID 出现；这不构成方法选择、实现确认或内容真值。

## 3. 零实例、零执行与 authority 边界

当前只存在 1 个隔离 rule contract schema 工件。`ruleCandidates`、`ruleDefinitions`、`ruleInstances`、`ruleImplementationInstances`、`ruleEvaluatorInstances`、`rulesetInstances`、`ruleFailureReceipts`、`ruleReceipts` 与 `successReceipts` 均为 0；`ruleBodiesIncluded=0`、`sourceBodiesIncluded=0`、`ruleEvaluationCapability=false`、`rulesetExecutionCapability=false`、`versionedRulesetGateSatisfied=false`。

零 failure receipt 只表示没有观察到执行，不能反推 evaluator、拒绝通道或验证能力已经存在。`ruleReceiptIssued=false`、`successReceiptIssued=false`、`ruleContractGateSatisfied=false`、`factContractGateSatisfied=false`、`inputContractGateSatisfied=false`、`countsTowardAdmission=false`。

## 4. 六层单向 DAG 与观察限度

rule requirements child 的 `chainOrder` 精确登记六个上游层级：

1. 产品边界 ADR；
2. input contract draft；
3. input contract requirements；
4. fact contract draft；
5. fact contract requirements；
6. rule contract draft。

这是一张按绑定集合验证的单向 DAG，不是把所有工件误写成彼此相邻的单链：rule draft 绑定前五层；rule requirements child 绑定前五层与 rule draft。child 不反向绑定 parent productization aggregator，也不绑定中央 registry，因此没有 child／parent raw-hash 循环。

held file handle、同一 Buffer 的 hash／parse、端点 identity revalidation、普通目录链与单链接端点只建立逐文件端点证据。当前明确 `crossFileAtomicSnapshot=false`、`ruleDraftAndRequirementsAtomicSnapshot=false`、`upstreamAndRequirementsAtomicSnapshot=false`、`intervalMutationExcluded=false`、`abaExcluded=false`、`mutationEpochAvailable=false`、`mutationEpochReceipt=null`；这些字段不证明跨文件原子快照、读取区间不变、ABA 排除或 mutation epoch。
