此后停止全仓构建、全仓类型检查、全量测试和开发服务。新增专项入口在读取前拒绝受限模块，而非替换模块内容或跳过失败后继续：

```powershell
node --import ./scripts/main-route-protected-source-guard.mjs ./node_modules/typescript/bin/tsc --noEmit --pretty false --project tsconfig.main-route.json
npx vitest run --config apps/web/vitest.main-route.config.ts
```

`tsconfig.main-route.json` 只限定类型检查入口，必须与禁读预加载器一同使用。Vitest 配置限定阅读相关测试，并在模块解析／加载前拒绝受限路径。守卫是指定命令入口的防误读措施，不是操作系统级完整访问审计。

完整应用启动入口仍导入该受限模块。因此在本轮限制未调整前，不重新启动完整应用、不构建最终完整包，也不创建会自动触发全仓 CI 的 PR。可单独同步非 `main` 的工作分支；按当前工作流配置，该分支单独推送不会触发这些任务。未运行的 CI 不能标为通过。
