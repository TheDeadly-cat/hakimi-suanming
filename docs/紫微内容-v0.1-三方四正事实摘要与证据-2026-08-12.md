# 紫微内容 v0.1：三方四正事实摘要与证据（2026-08-12）

## 1. 本轮结果

在继续保持 `packages/ziwei-workspace-artifact-draft` 为隔离草案的前提下，4218 Browser 研究预览新增了可操作的“三方四正事实摘要”：

1. 用户可以从十二宫选择任一问题宫位；默认选择命宫。
2. 页面明确列出本宫、对宫（`+6`）与两个三合位（`+4 / -4`）。
3. 每个关系宫显示已验真的本命主星、辅／杂曜、亮度和生年四化标记。
4. 十二宫盘面同步标出四个相关位置；所选本宫用实线强调，另外三宫用虚线标记。
5. 全部内容由主线程在完整 Browser 工件验真后只读派生；不接受 Worker 提供的解释文案，不修改工件、Revision 或 IndexedDB。

这一步完成的是用户目标中的“相关宫位有什么星、亮度与四化”事实底座，不是“这些星最终代表什么、吉凶如何”的专家解释层。

### 2.2 来源结论

- 三方四正几何可进入“传统规则／事实投影”层，因为规则可明确版本化且能从十二宫结构确定性重算。
- 亮度与四化只展示 Browser 工件中已经过 Schema、来源图和摘要门核对的字段；本轮不为其追加吉凶语义。
- iztro 文档同时提醒流派间四化与亮度存在差异，因此本轮保留项目既有规则快照，不声称跨流派统一。
- 现代网站和商业产品只用于产品流程参考；没有复制其文案，也没有把其自述转成验收真值。

## 3. 代码与数据边界

### 3.1 新增投影

`BrowserProbeDisplayProjection` 新增：

- `displaySanfangGroups`：十二个目标宫各自对应四个不重复关系宫；
- `sanfangProjectionRule`：固定规则 ID、方法、来源 URL、访问日期与 `interpretationIncluded:false / expertTruthClaimed:false`；
- 关系枚举：`self / opposite_plus_6 / trine_plus_4 / trine_minus_4`。

投影函数先要求十二个不重复地支宫，再按规范顺序派生四宫；宫位对象继续复用已经从验真工件本地生成的显示事实。

### 3.2 UI 边界

- 摘要默认命宫，但十二宫均可选择。
- 星曜不再受盘面“最多六颗”的视觉截断：四宫事实卡会列出该宫全部本命星曜。
- “无主星”只作为分类事实显示为“无主星（仅事实状态）”，不自动推导借宫、吉凶或人格结论。
- “生年四化”只写成如“紫微化科”的盘面标记，不解释禄权科忌的意义。
- 本轮没有新增保存字段、数据库表、写事务或 mutation epoch 例外。
