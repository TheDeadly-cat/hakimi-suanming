## 1. 本轮目标与选择理由

用户希望排盘后能直接看到“三方四正有什么星、代表什么内容、带来什么信息”，而不是只看到星名和几何关系。v0.7 已有逐宫直读复核包，v0.8～v0.10 又补齐本命生年四化候选、48 条四化落宫矩阵和离线审稿通道；但 4218 页面仍把本宫、对宫和两组三合位的内容分散在多层证据中，没有形成固定阅读顺序。

v0.11 因此先完成一条不需要新增专家语义、正式入口或历法授权的当前盘合成层：只从已经存在的十二宫问题域、十四主星 168 条落宫候选、逐星合参包、本命生年四化事实和三方四正几何中派生十二份四段式候选。它不临场发明辅曜、煞曜或杂曜含义，也不把会照关系换算成吉凶分数。

## 2. 在线资料审计与使用边界

本轮复核了以下公开资料与产品形态：

- [iztro 三方四正基础](https://docs.iztro.com/learn/basis)：用于核对本宫、对宫 `+6`、两组三合位 `+4 / -4` 的工程关系；页面自身也提示方法与流派存在差异。
- [iztro 宫位系统](https://docs.iztro.com/zh_TW/learn/palace)：继续承担十二宫问题域候选的现代资料定位。
- [iztro 四化资料](https://docs.iztro.com/zh_TW/learn/mutagen)：继续限定为本命生年四化观察来源，不扩写宫干飞化、自化、大限或流年。
- [《紫微斗数全书》卷一](https://zh.wikisource.org/wiki/紫微斗數全書/卷一)与[卷二](https://zh.wikisource.org/wiki/紫微斗數全書/卷二)：继续作为主星与宫位古典篇目定位，不直接转写确定人生结果。
- [周易网八字排盘页](https://www.zhouyi.cc/bazi/sm/)：只作为“排盘后立即给出位置相关内容”的交互形态参考，不进入紫微来源登记，也不作为紫微语义真值。

本轮没有新增紫微语义来源。四段式内容中的每个主星绑定继续指向已有基础候选、位置候选和逐星合参；来源链接随候选合并并去重。几何关系、内容候选、当前盘事实和人工判断是四个不同层次，不能互相冒充。

## 3. 十二宫 × 四段式确定性合同

每次已验真计算生成恰好 12 份候选，每份固定包含以下四段且顺序不可改变：

1. `palace_theme`／本宫主题：只消费 `self`；列出本宫问题域与本宫十四主星位置候选。
2. `external_pull`／外部牵引：依次消费对宫 `+6`、三合位 `+4`、三合位 `-4`；明确这些是会照来源，不改写成本宫落星。
3. `resource_pressure_observation`／资源／压力观察项：并列四宫的亮度与本命生年四化事实，但不判断哪一项是资源、哪一项是压力，不计算强弱或权重。
4. `contradiction_synthesis`／矛盾合成：给出本组逐星合参与四化事实数量，保留互补和牵制并存，不选择主导主题、不抵消矛盾。

每段都绑定：

- 明确的关系宫位及地支；
- 逐颗十四主星的 `synthesisId`、落宫候选 ID 与位置摘要；
- 亮度和本命生年四化数组；
- 本段实际引用的四化 occurrence ID；
- 来源引用、`ruleSnapshotSha256` 与 `artifactFactsSha256`。

每份根候选固定保持：

```text
selectedDominantTheme: null
resourcePressureOrientation: null
goodBadOrientation: null
eventOutcome: null
result: null
reviewStatus: awaiting_expert_review
publicationStatus: isolated_candidate_only
expertInterpretationIncluded: false
expertTruthClaimed: false
directOutcomeAllowed: false
scoringAllowed: false
```

真实空宫必须保持本宫主星集合为空，并明确“不借用对宫或两组三合位主星补写本宫主线”。当前三方组没有本命生年四化时，四化观察项保持空集合，不补入其他四化体系。

## 4. 4218 页面行为

当前宫位选择器下方新增一份“四段式直读候选”，旧的逐宫证据继续保留在其后：

- 页面一次只显示当前选择宫位的一份候选和四张卡；切宫时原卡被替换，不残留上一宫内容。
- 每张卡先直接给出中性陈述；关系、逐星 ID、四化 occurrence 与来源放在默认收起的“查看证据”中。
- 内容版本、两个事实摘要、关系／主星／四化计数及全部关闭字段均暴露为可自动核对的 data 属性。
- 页面明确提示：辅曜、煞曜和杂曜本轮仍只有盘面事实，尚无来源绑定的位置语义，不能被这四段暗中补写。
- 当前计算、切宫和渲染均不创建 Revision，不写 IndexedDB，也不推进 mutation epoch。

## 8. 尚未完成与下一目标

当前四段式已经把既有十四主星、宫位、亮度、四化和三方四正证据组织成可读顺序，但仍有清晰缺口：

1. 辅曜／杂曜当前只有名称、亮度和位置事实；工程没有可发布的“吉曜／煞曜”语义分类。
2. 下一项内容竖切应先建立核心十二星（左辅、右弼、文昌、文曲、天魁、天钺、擎羊、陀罗、火星、铃星、地空、地劫）的来源绑定基础候选，再形成 `12 × 12 = 144` 条落宫中性候选。
3. 传统“六辅／六煞”只能作为来源绑定的分组元数据，必须另设“分组不等于个人吉凶结果”的关闭字段；不能按类别或数量给当前命盘加减分。
4. 有了上述语义原子后，才能在下一层把真实命中星曜接入当前四段式；禄存、天马、其他 minor 与 auxiliary 仍应失败关闭，不能按上游 category 广播文案。
5. 四段式本身仍需要独立的当前盘审稿反馈模板；专家意见也只能先只读预检，不能自动写规则、Revision 或正式入口。

本轮未提交、未暂存、未提升 v15/v16 默认代、未绕过 mutation epoch，也没有取得专家真值、正式吉凶授权、Android 设备证据或正式紫微入口授权。
