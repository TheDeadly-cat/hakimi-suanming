# 八字内容 v0.16：审稿反馈模板与只读预检

- 日期：2026-08-12
- 状态：Web v1 内部收口；未提交、未暂存、未发布
- 反馈 Profile：`hakimi.bazi.content_review_feedback/0.1.0`
- 模板版本：`0.16.0`
- 固定文件名：`hakimi-bazi-content-review-feedback-v016.json`
- 默认发布身份：`legacy-v13 / targetSchema 13 / migrationId null`
- 本轮不声称：专家真值、正式吉凶、现实身份核验、数字签名、自动整合、正式激活、Android 设备验收、JPL 官方参考字节、紫微/西洋正式入口或 v15/v16 默认代

## 1. 本轮目标

v0.14 已有 69 项八字内容审稿清单，但只有只读导出，没有一份可以交给用户或专家离线填写、再回到浏览器做失效关闭预检的反馈合同。

v0.16 补齐以下内部闭环：

1. 从当前 `BAZI_CONTENT_REVIEW_QUEUE` 确定性生成 69 项空白反馈模板；
2. 用 SHA-256 同时绑定完整队列序列化字节和有序审稿项 ID；
3. 允许线下填写具名审稿信息、逐项决定、理由、退修要求与补充 HTTPS 来源；
4. 回到浏览器后只做结构、版本、覆盖、快照、摘要和归属预检；
5. 无论填完多少项，预检都不写命盘、不写数据库、不越过 mutation epoch，也不自动激活任何内容。

这是一条“收集可归属反馈”的工程通道，不是专家身份认证系统，也不是内容发布系统。

## 3. 反馈合同

### 3.1 确定性模板

模板固定包含当前 69 项候选快照，每项保留：

- `reviewItemId` 与原顺序；
- 类别、标题、审稿问题与候选摘要；
- 当前 `sourceRefIds`；
- 空白 `decision`、`decisionReason`、`revisionRequest` 与 `additionalSourceUrls`；
- 固定 `result:null`。

当前绑定值为：

```text
queueProjectionVersion: hakimi.bazi.content_review_queue/0.1.0
queueCatalogVersion: 0.14.0
queueSha256: 104efa7746567fe4bba5edd70e7a037798fc680a2aee9cde9e65ac1ef71e54d9
orderedItemIdsSha256: 22f039549578ee1f498510c4cd8d332453c5a13e9ef780488d23b84114f9a6dc
itemCount: 69
```

只要队列内容、顺序、ID、摘要或声明数量变化，旧反馈文件就不能通过当前预检。

### 3.2 可填写字段

线下填写范围限定为：

- `reviewer`：ID、显示名、机构、专业说明；
- `reviewSession`：ISO 时间、方法说明；
- 逐项 `decision`：`unresolved / approve / revise / reject`；
- 决定理由、仅退修时允许的退修要求；
- 补充 HTTPS 来源链接；
- 与逐项决定完全一致的声明计数。

任一人类反馈字段出现后，必须完整填写审稿人 ID、显示名、专业说明、审稿时间和方法；这只证明文件具有自我声明的归属，不证明现实身份或专业资质已核验。

### 3.3 固定关闭字段

模板、逐项记录和预检结果固定保持：

```text
identityVerified: false
digitalSignatureVerified: false
eligibleForFormalActivation: false
autoIntegrationAllowed: false
chartOrStorageMutationPerformed: false
result: null
```

即使 69 项全部填写为 `approve`，上述字段仍不能改变。后续若要整合，仍必须在线下核验身份和资质，并经过人工代码审查、独立测试与明确发布授权。

## 4. 失效关闭规则

预检会拒绝：

- 非法 JSON、额外字段、缺字段或 Profile/版本不匹配；
- 不是恰好 69 项，或 ID 覆盖、顺序、候选快照、来源引用发生变化；
- 队列摘要、有序 ID 摘要或声明计数不匹配；
- 已裁决项没有理由，`revise` 没有退修要求，或非 `revise` 项带有退修要求；
- 出现人类反馈却缺少完整 reviewer / reviewSession 归属；
- 补充来源不是 HTTPS、重复或不符合字段约束；
- 身份核验、签名、正式激活、自动整合、mutation 或 `result` 被擅自改为开放状态。

UI 只接受 UTF-8 JSON，最大 2 MiB；允许 UTF-8 BOM。任何一次非法导入都会清空前一次有效预检状态，回到 `0 已裁决 / 69 未决`，防止旧结果残留造成误读。
