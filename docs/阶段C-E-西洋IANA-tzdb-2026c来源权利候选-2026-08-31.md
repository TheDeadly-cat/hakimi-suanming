## 1. 结论

本轮可以建立两个 partial candidate，但仍不能冻结任一 Binding：

1. `western.input.calendar-time-zone-and-dst`：只覆盖 IANA release 身份、bundled packed data 身份和既有 gap／overlap 工程实现所依赖的数据版本；不覆盖完整历法语义、所有时区历史真值或工程复现 reviewer 意见。
2. `western.rights.ephemeris-time-data-redistribution`：只覆盖 IANA tzdb 2026c data 与 `moment-timezone@0.6.3` 这一条时区数据／转换载体链；不覆盖 JPL／NAIF kernel、IERS／EOP、闰秒、其他 provider 或组合产品的法律许可。

因此两条都必须保持 `candidate_only_unbound / subjectFullySatisfied=false / frozenBindingId=null`。本轮不把公开许可文字自动转换成法律判断，也不把相同版本字符串当作 IANA 原始数据与 moment packed transformation 的逐字等价证明。

## 4. 作品、版本、载体三层分账

| 层级 | 当前观察 | 未建立 |
| --- | --- | --- |
| 作品层 | IANA tzdb LICENSE public-domain 文字；moment-timezone MIT 文字 | 法律适用判断、其他依赖与最终产品组合许可 |
| 版本层 | IANA `2026c`；moment-timezone `0.6.3`；固定 npm SRI | packed transformation 与 IANA archive 的完整派生证明 |
| 载体层 | IANA data tarball、detached signature、npm tarball、本地 packed/meta/package/license exact bytes | signing key trust、publisher identity、未来 CDN freshness、正式分发载体清单 |

三层都只能登记 `evidence_observed`，不能登记 `rightsEstablished=true`。公开许可文字也不能由生成模型解释为法律结论；正式权利 reviewer、owner decision 与必要法律复核仍为 0。

## 5. 本轮存储与隐私边界

IANA archive、signature、release/announcement 页面、version／LICENSE representation 和 npm tarball 都只在进程内读取、hash、解析后丢弃；没有把远程 body、archive、signature、LICENSE 全文或 npm tarball写入仓库。仓内只保存本项目自写摘要、URL、bytes/hash、少量 exact quote 与现有依赖文件 identity。

本轮没有登录、没有访问第三方后台、没有联系任何个人、没有复制 prompt／知识库／付费材料，也没有持久化私人数据。
