# 八字内容 v0.6：旺衰、十神与神煞同柱复核包及证据

日期：2026-08-12  
状态：Web v1 只读同柱合参投影已实现并完成定向工程验收；综合结果与神煞取向仍固定为 `null`

## 1. 本轮结论

本轮把已经存在的三层内容在同一柱位上连接起来：

1. 旺衰层：日主强弱的可审计规则候选；
2. 十神层：十神落年、月、日、时的位置文案，以及相对当前旺衰候选的平衡方向；
3. 神煞层：五条年柱基准命中事实与 5×4 原创位置议题候选；
4. 同柱复核层：只在十神位置与神煞命中落到同一柱时生成一份并排事实包。

同柱复核包会直接告诉用户“这一柱同时出现哪颗十神与哪项神煞议题”，并给出三条可由现实经历核对的问题。它不会把十神的“偏有利 / 需警惕 / 条件性”转嫁给神煞，也不会生成新的综合方向。

每个复核包固定为：

- `evidenceClass: derived_read_only_projection`；
- `reviewStatus: candidate_pending_expert_review`；
- `result:null`；
- `overallOrientation:null`；
- `shenshaOrientation:null`；
- `expertTruthClaimed:false`；
- `directOutcomeAllowed:false`；
- `scoringAllowed:false`。

因此，本轮完成的是“同柱内容组织与复核接口”，不是“把神煞判成吉或凶”。

## 3. 来源与编辑边界

### 3.1 没有新增命理规则

本轮是已有字段的只读派生投影，没有新增“某十神遇某神煞必然如何”的组合规则。每个复核包只合并已有来源 ID：

- 旺衰与十神沿用 [《滴天髓阐微》· 衰旺](https://ctext.org/wiki.pl?chapter=826601&if=gb)、[《三命通会》卷五](https://zh.wikisource.org/zh-hans/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%BA%94) 与 [《三命通会》四库全书本卷十](https://zh.wikisource.org/zh-hans/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B710) 的既有来源账；
- 将星、华盖、咸池沿用 [《三命通会》卷二](https://zh.wikisource.org/wiki/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%BA%8C) 的既有主题定位；
- 驿马、天乙贵人沿用 [《三命通会》卷三](https://zh.wikisource.org/wiki/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%B8%89) 的既有主题定位；
- 十神 10×4 与神煞 5×4 用户文案仍是本项目原创待审编辑层。

本轮没有从典籍中摘取新的结果断语，没有复制命理网站的用户文案，也没有把在线资料当成个案真值。

### 3.2 方向归属

同柱卡中的方向标签只读取 `PillarTenGodReading.orientation`：

- `favorable`：十神相对当前旺衰候选的平衡方向为“偏有利”；
- `challenging`：十神相对当前旺衰候选的平衡方向为“需警惕”；
- `conditional`：当前旺衰接近中和、未定，或该十神不能单项定向。

神煞不参与这三个标签。卡片同时暴露 `data-ten-god-orientation`、`data-shensha-orientation="null"` 与 `data-overall-result="null"`，避免视觉文案把三者混为一谈。

## 8. 尚未跨越的边界

- 同柱只表示两个已有候选落在同一柱，不能证明二者存在传统组合关系、因果关系或强弱加成。
- 十神方向仍依赖 0.1.0 旺衰工程权重与阈值；特殊格、合化、调候、刑冲引动与运限尚未进入最终裁决。
- 神煞仍没有个案方向，不允许借用十神标签称其为吉或凶。
- 三条问题是现实复核接口，不是问卷诊断，也不会自动汇总成分数。
- 复核包没有预测婚恋、健康、生育、财富、职业、迁移、灾祸、寿命、法律或具体时间事件。
- 工程测试、浏览器渲染和内容 ID 只证明当前投影自洽，不认证命理正确性或专家真值。
- 本轮没有取得正式入口、正式发布、默认代提升、Android 设备、专家真值或 JPL 官方字节授权。

因此，本轮可以声明“旺衰、十神与神煞同柱复核包的只读工程链已经闭合”，不能声明“神煞吉凶已经判定”“综合结论已经正确”或“项目已经达到正式发布条件”。
