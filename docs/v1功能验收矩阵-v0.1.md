## 4. v1 最终闭环验收场景

必须有一条自动化主流程，不能用一组互不关联的单元测试代替：

1. 在全新浏览器安装 PWA 并完成基础资源下载；
2. 导入包含正常、重复、错误和未知时辰的 CSV；
3. 打开一个案例，查看民用时、真太阳时和候选时辰；
4. 从选定的确切历史 Revision 派生另一规则配置并保存 Rn，确认来源 Revision 内容与摘要不变；
5. 分别编辑并收藏 Case/CandidateSet，执行移入回收站与恢复；对一次性测试记录执行永久删除并核对关联与重复指纹边界；
6. 查看原局至流时，在某节点分别记录上海分钟事件与纽约 DST overlap 事件，确认 gap 被拒绝、earlier/later UTC 不同，并通过精确事件深链与节点双向返回；再从一个合法旧 `legacy_floating` minute/day 夹具显式派生新 ID，核对源未改写、并列解释、回执、同 ID 冻结及内容/生命周期可编辑；
7. 与另外三盘并排，查看盘间与规则差异；
8. 从字段打开依据条和精确版本原文，核对来源权利与四项依据覆盖；从事件卡点击“按此事件条件检索”，核对只含草稿 UUID 的地址、严格上下文边界和结果后，再保存筛选视图；
9. 断网后继续搜索、排盘、对照和导出；
10. 导出匿名 PDF/Markdown 与全量备份；
11. 清空当前数据，在另一浏览器恢复；
12. 验证记录、关联、设置、引用、附件、`favorite/deletedAt` 生命周期状态、CandidateSet v1/v2 回执、Event v2 时间上下文、Event 时间派生回执与命盘复算哈希一致；旧 CandidateSet v1 回执保持冻结比较语义，旧包 Event v1 仍保持 `legacy_floating`，full v1.0 先按冻结十四分区格式验真后才迁移为空 Event 回执分区；
13. 未配置 AI 时以上全部成功；配置测试 Provider 后，AI 可带引用总结笔记，但无法修改计算事实。

> 当前普通构建与默认发布身份仍为 `legacy-v13`；面向 v13 用户的 v16 只存在于隔离 candidate。该 candidate 的连续 Web v1 门在 Edge、Chrome 各通过 1/1、共 2/2，配套升级故障矩阵各 12/12，clean 万条容量子门第二次启动分别为 1.072 秒与 1.066 秒且 `epoch=verifiedEpoch=1`。这些当前代码实证仍未覆盖全部 DST 场景、AI Provider、PWA 安装后独立窗口、Firefox、固定 Android Chrome/WebView 或真实系统安装 UI，也不是专家真值；因此不能替代场景 1～13 的最终发布签字，更不能据此把 v16 提升为默认代或宣称 Android/v1 完成。

任一步失败，v1 都不能标记完成。

## 5. 推荐实现顺序

1. 锁定 Schema、备份格式和版本字段；
2. 完成 `bazi-core`、校时与 360 个金标准输入；
3. 完成规则包框架、传统子平工作配置和运限引擎；
4. 建立 IndexedDB/OPFS 仓库、迁移与全量备份恢复；
5. 完成案例、修订、事件、检索、保存视图和依据条；
6. 完成批量导入、多盘/多规则对照、典籍索引、来源权利台账、依据覆盖审计和导出；
7. 接入 PWA 离线壳，再做桌面/手机功能等价；
8. 接入 AI Provider 契约与可选兼容端点；
9. 完成跨浏览器、离线、升级回滚、容量、隐私和无障碍验收；
10. 通过 Web/PWA 的连续主流程、离线、升级回滚、容量、隐私和无障碍发布门后发布 Web v1；随后再建立 Capacitor Android 测试壳，验证同一备份和命盘哈希后进入 APK 阶段，iOS 暂缓。

## 6. 三个 Web 体系功能完成后的 Android 阶段门

本矩阵当前仍负责八字 Web v1 验收；用户已决定，Android 不在八字 v1 完成后立即启动，而要等待八字、紫微斗数和西洋占星三个 Web 模块分别达到约定功能与独立质量门。

1. 建立最小 Capacitor 测试壳，不在壳内复制排盘或研究逻辑；
2. 将 Web v1 导出的同一备份导入测试壳，复核记录、关联与命盘哈希；
3. 验证 Android 文件选择、分享、返回键、离线重启与系统 WebView 升级；
4. 通过固定安卓设备矩阵后再生成和签名 APK；当前不建立 iOS 工程。

## 7. 发布前必须锁定的决定

- 传统子平工作配置的具体版本、默认换日方式和来源；
- 强校验年份范围；
- AI 暂缓、用户兼容端点或项目服务三者之一。

这些决定不妨碍先建立版本化架构，但在金标准验收前必须确认。
