# 阶段 C：八字政策权重逐值证据候选 v1

## 本轮范围

`bazi-policy-weights-value-evidence-candidate.v1` 只对当前 `binding:policy:weights` 的三项既有 value-subject 做端点观察：

1. `BAZI_STRENGTH_FACTOR_WEIGHTS` 的当前四个整数值：月令 `4`、透干 `2`、首位藏干 `2`、其余藏干 `1`；
2. `strengthFactorWeight` 的当前直接 dispatch 语法投影与非负整数藏干索引失败关闭；
3. `collectBaziStrengthFactors` 中月令、透干、带索引藏干的三个直接消费调用形状。

它复用现有 engineering candidate、value-subject gap 与 freeze requirements 身份，不创建平行 binding、不注册新 EvidenceSubject、不接入 domain manifest 或 central registry，也不重签任何父账。

## 读取与观察边界

candidate 和五份 basis 都经过 held-handle 有界读取。文件打开前、打开后和读取后会重新核验目录链、realpath、文件身份与稳定元数据；symlink/junction、hard link、端点替换和越界路径均失败关闭。每个文件的 hash、JSON parse 或 TypeScript AST 检查复用同一个 held-handle Buffer。

这仍只是无 mutation epoch 的端点观察：release 身份用 `mutationEpochRequiredBeforeAnyFutureFreeze=true` 与 `mutationEpochAvailableForSchema13=false / mutationEpochReceipt=null` 成对表达“未来冻结前必须有，但当前 schema 13 没有”；同时 `crossFileAtomicSnapshot=false`、`intervalMutationExcluded=false`、`abaExcluded=false`。语法投影不声称一般 control-flow/data-flow 等价，也没有执行运行时算法。

## 权威边界

candidate 固定保持：

- `bindingFreezeEligible=false`；
- `bindingFrozenVerified=false`；
- `engineeringRationaleFrozen=false`；
- source evidence 为空，source rights/carrier/rationale record 为 `null`；
- engineering/expert/domain review ID 为空；
- `legacy-v13 / targetSchema 13 / migrationId null`；
- 内容真值、专家真值、权利法律结论、发布就绪与公开发布授权全部未建立。
