## 1. 本轮结果

v0.17 关闭了两个可以只靠当前工程完成的内部缺口：

1. 把旺衰执行口径收敛到一个可序列化的单一事实源。真实权重固定为“月令 4、透干 2、首位藏干 2、其余藏干 1”；当月支首位藏干与月令同时命中时，当前工程候选会合计为 6。五档阈值、十神分组／方向、六个敏感性场景与四个方法审稿问题也由同一政策对象提供。
2. 新增“本盘实际命中复核包”。它不再要求审稿人从 69 项全量目录里自行寻找当前命盘，而是只输出本盘的 4 个旺衰方法项、实际透干／藏干十神出现项，以及用户显式打开神煞研究后实际命中的神煞落柱项。

这不是把旺衰或神煞判成吉凶。系统允许审稿人提交 `potentially_supportive / potentially_challenging / mixed_conditional / not_assessable` 的**条件化提案**，但最终 `goodBadOrientation / eventOutcome / result` 仍全部为 `null`。

这次是工程政策账和文字纠偏，不是专家确认该权重具有命理真值，也不是把数值评分包装成科学测量。

## 3. 当前盘复核包合同

实现位于 `packages/bazi-interpretation/src/current-chart-hit-review.ts`：

- Profile：`hakimi.bazi.current_chart_hit_review/0.1.0`
- 内容版本：`0.17.0`
- 固定文件名：`hakimi-bazi-current-chart-hit-review-v017.json`
- 工作方式：`human_attributed_read_only_preflight`
- 最大文件：2 MiB
- 自动整合：关闭
- 命盘／存储写入：关闭

包内只保留复核所需的最小四柱事实、旺衰政策与敏感性快照、实际十神／神煞候选、使用到的来源以及逐层摘要。姓名、案例 ID、Revision ID、原始表单、地点、日历输入文字和正式清单中的其他未命中候选不进入文件。时辰不可靠时，时柱事实与时柱命中项明确 withheld，不补猜。

摘要使用带域分隔的 canonical JSON SHA-256，绑定：

- 当前最小事实投影；
- 旺衰政策；
- 旺衰判断与六场景敏感性；
- 当前十神／神煞出现项；
- 本次使用的来源表；
- 有序复核项 ID；
- 完整当前盘 packet。

SHA 只用于发现内容变化，不是数字签名、身份认证、加密或专家背书。预检会用当前内存命盘重建完整 packet；只篡改候选后再重算包内 SHA 也不能通过。

## 4. 人工意见边界

任何非空人工意见都必须同时提供 reviewer ID、显示名、专业说明、合法 ISO 审稿时间与方法说明。已裁决项必须填写：

- 条件化方向；
- 所采用的传统／流派范围；
- 理由；
- 成立条件；
- 反例；
- `revise` 时的修改要求。

补充来源只接受受限的 HTTPS URL。即使所有项目全部 `approve`，仍固定：

`identityVerified:false`、`digitalSignatureVerified:false`、`expertTruthClaimed:false`、`scientificValidityClaimed:false`、`eligibleForFormalActivation:false`、`autoIntegrationAllowed:false`、`catalogDecisionInheritanceApplied:false`、`networkTransmissionPerformed:false`、`chartOrStorageMutationPerformed:false`。

## 5. Web 接入

`apps/web/src/components/bazi-interpretation-panel.tsx` 在神煞研究预览之后、69 项全量审稿台之前新增独立面板：

1. 初始不生成神煞命中；用户点击“准备当前盘复核包”后才在内存中显式打开本次只读研究门。
2. 下载与文件预检只对当前成功准备的命盘开放。
3. 绑定键使用当前 Revision、结果摘要与时柱可靠性；切换 Revision 会立即清空旧模板和预检结果。
4. 文件读取使用 epoch/read token；跨盘迟到结果不会落到新命盘。
5. 非法或错盘文件先清掉旧的有效预览；用户取消文件选择则保留同盘状态。
6. 文件交付失败不会把尚未改变的内存 packet 错标为“预检无效”。

面板不写 IndexedDB、localStorage、sessionStorage 或 Cache Storage，也不调用正式规则激活路径。

## 6. 在线资料怎么用

本轮先把竞品与来源拆成“信息架构参考、编辑语法候选、传统文本定位、工程事实”四层，禁止互相冒充：

- [周易天地八字排盘入口](https://www.zhouyi.cc/bazi/sm/)的静态页可用来观察输入信息架构；本轮没有把其动态结果页当作已实测算法。
- [日主旺衰文章](https://m.zhouyi.cc/bazi/sm/43679.html)展示“得时／得势／得地—生扶或克泄”的编辑语法，并自行提示量化法并不严谨；只能作为竞品内容结构，不是当前 4/2/2/1 的证明。
- [十神落四柱文章](https://m.zhouyi.cc/bazi/sm/21128.html)可提示“十神 × 年月日时”的页面组织方式；其现代文案不可直接复制，也不能越成确定事件。
- [驿马文章](https://m.zhouyi.cc/bazi/sm/14460.html)采用年支或日支查法，恰好显示学派／公式冲突；当前规则若只实现一种基准，必须登记差异而不能静默扩张。
- [《滴天髓阐微》Wikisource](https://zh.wikisource.org/wiki/滴天髓闡微)、[《三命通会》卷五](https://zh.wikisource.org/wiki/三命通會/卷五)与[《渊海子平》](https://zh.wikisource.org/wiki/淵海子平)用于定位传统文本；社区转录仍需与可靠影印逐字校核。

竞品网页受现代版权约束，本项目只学习信息结构、问题拆分和风险边界，不复制其长段文案。传统文本只能证明某种历史说法或术语出现过，不能证明科学有效性或当前人的事件结果。
