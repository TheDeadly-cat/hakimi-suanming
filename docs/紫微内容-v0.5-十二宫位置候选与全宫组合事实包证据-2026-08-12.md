# 紫微内容 v0.5：十二宫位置候选与全宫组合事实包证据

日期：2026-08-12  
状态：隔离 Web 草案已实现并完成定向工程验收；内容仍待命理专家逐条复核

## 1. 本轮结论

本轮把紫微显示投影从“十四主星 × 命财官迁四宫”扩展为“十四主星 × 十二宫”：

- 位置候选版本由 `ziwei.major_star_core_palace.neutral_candidate/0.1` 升为 `ziwei.major_star_all_palaces.neutral_candidate/0.2`；
- 保留原命、财帛、官禄、迁移四宫的 56 条人工短解；
- 为兄弟、夫妻、子女、疾厄、交友、田宅、福德、父母八宫新增 112 条原创中性候选；
- 静态注册表合计 `14 × 12 = 168` 条，内容 ID 与位置摘要均不重复；
- 组合事实复核版本由 `ziwei.major_star_core_palace.combination_review/0.1` 升为 `ziwei.major_star_all_palaces.combination_review/0.2`；
- 当前盘面全部 14 颗主星均生成亮度、生年四化、同宫、对宫和两组三合位的事实包；每包仍有四个待审问题且结论固定 `result:null`；
- 任意十二宫三方组都可显示其主星的位置候选与组合事实包，辅曜和杂曜仍不接主星内容。

这是一条只读内容竖切：没有改变 Worker 计算、Browser 工件、Revision、IndexedDB、备份格式或 mutation epoch。

## 3. 在线资料审计与使用边界

### 3.1 宫位问题域

- [iztro 宫位系统](https://docs.iztro.com/zh_TW/learn/palace)：用于核对十二宫的现代问题域，以及“本命宫位内容是观察态度或关注域、不能直接当成事件吉凶”的边界。
- [iztro 星盘结构](https://docs.iztro.com/learn/astrolabe)：用于核对十二宫盘面、星曜与三方四正合参的显示关系，并区分本命层和运限层。
- [iztro 三方四正基础](https://docs.iztro.com/learn/basis)：只用于本宫、对宫和两个三合位的位置关系，不按星数或关系名称自动评分。

### 3.2 古典定位

- [《紫微斗数全书》卷二](https://zh.wikisource.org/wiki/紫微斗數全書/卷二)：只作为十二宫逐星条目的节次定位；界面标签继续使用现代的“夫妻宫”“交友宫”，不复制“妻妾”“奴仆”等历史身份措辞。
- [《紫微斗数全书》卷三·谈星要论](https://zh.wikisource.org/wiki/紫微斗數全書/卷三)：只用于确认传统合参会同时考虑亮度、四化、同宫和三方条件；不采用其中的富贵、灾祸、疾病、寿命或身份结论。

### 3.3 亮度与四化

- [iztro 星曜系统](https://docs.iztro.com/zh_TW/learn/star)：保留盘面既有亮度事实，但不把庙旺自动映射成吉、得分或结果。
- [iztro 四化资料](https://docs.iztro.com/zh_TW/learn/mutagen)：本轮只展示已验真的本命生年四化，不补写宫干或运限四化。

所有新增句子均为本项目的编辑性重组，不复制网页文案。网页资料、古籍定位和工程事实都不是命理专家批准。

## 4. 十二宫内容边界

| 宫位 | 本轮问题域 | 明确禁止的单项结论 |
| --- | --- | --- |
| 命宫 | 自我定位、回应方式、人生关注点 | 人格定型 |
| 兄弟宫 | 手足、同辈协作、资源往来 | 手足数量、关系结果 |
| 夫妻宫 | 亲密关系、承诺方式、相处边界 | 婚期、婚姻结果、性别刻板断语 |
| 子女宫 | 亲子、培育、创作、合作输出 | 生育能力、子女数量、亲子结果 |
| 财帛宫 | 财务态度、资源交换、物质需求 | 财富多寡、投资建议 |
| 疾厄宫 | 身体使用、恢复节奏、日常负荷 | 疾病诊断、寿命、医疗替代 |
| 迁移宫 | 外部环境、陌生场域、公开互动 | 异地成败 |
| 交友宫 | 社交圈、协作网络、沟通选择 | 指定个人可信、背叛或身份 |
| 官禄宫 | 工作态度、任务结构、责任分工 | 指定职业或成就 |
| 田宅宫 | 家庭空间、收藏、安定感、长期积累 | 置业、继承、资产规模或家庭结果保证 |
| 福德宫 | 内在思考、精神休息、价值感受 | 心理诊断、固定性格标签 |
| 父母宫 | 长辈互动、早期支持、制度文书关系 | 父母健康、寿命或家庭命运 |

新增八宫短解由“冻结星曜表达线索 × 宫位问题域”组成。例如，天机落交友宫只把“分析、策划与随情境调整”呈现为社交与协作问题的观察线索；它不会继续推导朋友好坏或具体事件。

### 5.3 全宫组合事实包

`packages/ziwei-iztro-adapter-draft/src/browser-preview/major-star-combination-review.ts`

- 动态数量必须等于盘面全部主星数量，本次默认工件为 14；

- `interpretationIncluded:false`、`expertTruthClaimed:false`、`directOutcomeAllowed:false`、`scoringAllowed:false` 和 `result:null` 不变。

### 5.4 显示与自动化

- `display-projection.ts` 为十二宫全部主星挂载位置候选和组合包；
- 4218 页面标题与边界说明更新为十二宫 168 条；

- Playwright 主链新增断言：切到兄弟宫三方组后，位置候选和组合包数量必须与该组主星数量一致，且每个组合包继续 `awaiting_expert_rule / result:null`。
