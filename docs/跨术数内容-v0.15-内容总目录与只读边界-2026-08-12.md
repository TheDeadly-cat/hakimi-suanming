# 跨术数内容 v0.15：内容总目录与只读边界

- 日期：2026-08-12
- 状态：Web v1 内部收口；未提交、未暂存、未发布
- 目录 Profile：`hakimi.research.content_catalog/0.1.0`
- 默认发布身份：`legacy-v13 / targetSchema 13 / migrationId null`
- 本轮不声称：专家真值、正式吉凶、JPL 官方参考字节、Android 设备验收、紫微/西洋主应用入口或 v15/v16 默认代

## 1. 本轮目标

在不导入隔离草案包、不开放 4218/4219 主应用入口的前提下，为八字、紫微斗数和西洋星盘建立一张用户可见、只读、可审计的内容总目录。目录回答五个问题：

1. 当前固定内容有多少、以什么单位计数；
2. 已登记多少来源，哪些代表链接可以直接核对；
3. 盘面运行时还能派生哪些阅读层；
4. 哪些内容仍未完成或未获批准；
5. 当前是否拥有主应用入口、专家真值或正式发布资格。

本轮没有把三套术数内容合并到同一算法，也没有把不同单位的数量相加成“总内容量”或完成度。

## 4. 在线样本与资料边界

本轮在线抽查确认：

- 用户给出的[易安居八字排盘页](https://www.zhouyi.cc/bazi/sm/)把日期类型、出生时间、出生地点、真太阳时、姓名与性别集中在排盘入口，并明确写有休闲娱乐提示。它只作为信息架构和输入提示样本，不进入命理内容来源登记，也不复制其文章断语。
- [紫微研习社十四主星](https://docs.iztro.com/learn/major-star)同时呈现十四主星、组合与三方四正相关学习内容，并明确提醒星曜特质需要其他条件修正、作者描述不一定百分之百准确。v0.15 只把既有隔离草案的中性候选与来源数量做静态目录化。
- 西洋目录保留 [Astrodienst 解释边界](https://www.astro.com/astrowiki/en/Limits_of_Interpretation)与 [Nature 双盲研究](https://www.nature.com/articles/318419a0)链接，分别标示解释边界与科学边界；占星候选不声称科学因果或确定事件预测。

来源可访问不等于内容已经获得专家批准；外部网站的版权、署名和许可仍归各自页面。

## 6. 失效关闭契约

目录构建器会拒绝：

- 三体系缺项、重复或顺序变化；
- 69/194/43 或 10/8/31 被静默修改；
- 分项合计与固定目录不一致；
- 代表来源重复、为空或不是 HTTPS；
- 紫微/西洋出现运行时入口；
- 专家批准、正式发布、`goodBadScore` 或 `result` 被非授权填入。

页面根节点与每张卡显式暴露只读审计属性，包括：

```text
data-runtime-import-policy="isolated_draft_imports_forbidden"
data-navigation-policy="no_draft_runtime_entry"
data-scoring-allowed="false"
data-expert-truth-claimed="false"
data-formal-activation-allowed="false"
data-good-bad-score="null"
data-result="null"
```

本轮没有读写 mutation epoch，也没有新增 IndexedDB mutation 路径。
