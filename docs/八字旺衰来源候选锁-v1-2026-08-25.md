## 4. 权利判断保持失败关闭

固定页面可观察到公版提示或站点 CC BY-SA 提示，但“页面有提示”不等于本项目已经完成作品层、现代版本层和载体层的法律审查。Wikimedia 使用条款要求重用者遵守底层许可证的署名等要求；CC BY-SA 4.0 对分享材料要求保留署名、许可提示和来源链接，并在修改时标明修改，改编还可能触发相同方式共享条件：

- [Wikimedia Terms of Use：Licensing of Content](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use/en#7._Licensing_of_Content)
- [CC BY-SA 4.0 legal code](https://creativecommons.org/licenses/by-sa/4.0/legalcode)

因此四条候选统一保持：

```text
carrierType = link_only
storagePolicy = link_only
sourceBodyStored = false
quoteTextStored = false
repositoryCarrierFileStored = false
repositoryPageImagesStored = false
rightsReviewAttestations = []
distributionDecision = link_only
legalConclusion = not_established
```

这不是法律意见，也不表示引用例外、精神权、版本来源、转录贡献或再分发义务已经核清。

- 在没有现实复核的情况下改为 redistributable；
- 把 `bindingFrozenVerified` 从 0 提高。

## 6. 明确阻塞：`binding:zpzz:review-gates`

[中国哲学书电子化计划《子平真诠评注》工作元数据页](https://ctext.org/wiki.pl?if=gb&res=631975) 当前明确写明“版本（电子版所应按照的底本）：暂缺”。因此现有章节 locator 不能建立底本／版本身份，也不能进入本候选账。公开可见的《子平真诠》原书影印只能说明原作载体存在，不能替代徐乐吾评注层的作品、版本和载体身份。

该 binding 继续保持 `pending_manual_textual_verification`。解除阻塞至少需要：可公开核验的徐乐吾评注可靠底本、章节与页码对应、最小引文 hash、作品层／评注版本层／载体层权利依据，以及后续现实专家复核。付费、积分下载或标注 All Rights Reserved 的第三方载体不得被绕过访问或复制。

## 7. 未完成线

每条 binding 真正晋级仍至少需要：

1. 为四条候选 binding 取得与目标版本关系明确的可靠影印／底本，完成逐字校勘并冻结明确版本身份；当前四个锚点只完成旁证／同作品后出版本定位；
2. 在有权保存的证据库中核对最小充分引文字面与当前 quote SHA-256；
3. 分别完成作品层、版本层、载体层权利依据；
4. 两名现实来源／权利复核者签署；
5. 两份现实领域专家意见并列保存；
6. 解决审计概念主题与当前 binding 粒度不一致的问题；
7. 生成正式 KnowledgeDocument、CitationRecord、SourceRightsRecord 与 SourceCarrierRecord 闭环。

在这些条件满足前，`bindingFrozenVerified=0/12`、`sourceBundleComplete=false`、`rightsBundleComplete=false`、`expertClaimsAuthorized=false`、`publicDeploymentAuthorized=false` 均不得改变。
