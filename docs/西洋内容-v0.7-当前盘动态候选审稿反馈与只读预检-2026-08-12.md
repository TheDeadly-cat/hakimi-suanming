# 西洋内容 v0.7：当前盘动态候选审稿反馈与只读预检（2026-08-12）

> 性质：Schema 16 / Web v1 当前未提交工作区中的隔离 4219 草案增量。本文记录工程契约与本轮新证据，
> 不授权西洋正式入口、默认发布代提升、专家真值、科学有效性、吉凶结论或具体事件预测。

## 1. 本轮收口目标

v0.6 已把 10 天体、12 星座、12 宫位、5 相位与 4 轴点拆为固定 43 项基础内容审稿，但明确不能
替代某一张实际命盘的动态组合复核。v0.7 关闭这一工程缺口：让用户在成功排盘后，主动下载当前
`WesternContentProjection` 的逐卡审稿包，再把有归属、传统范围、成立条件与反例的反馈只读导入。

这仍不是把反馈自动写回产品。导入成功只说明：反馈文件与当前内存命盘的内容快照严格一致，且字段
满足契约；不说明审稿人身份已核验、意见为专家共识、占星获得科学验证或内容可以正式激活。

## 2. 动态候选与计数

外部审稿顺序与当前页面渲染顺序一致：

1. 四步首读 `firstRead`；
2. 逐星综合 `bodySyntheses[]`；
3. 非空命主星 `chartRuler`；
4. 定位星链 `dispositorChains[]`；
5. 非空四轴距离账 `angleProximity`；
6. 四轴 `angles[]`；
7. 元素／模式分布 `distribution`；
8. 宫主星 `houseRulers[]`；
9. 落位 `placements[]`；
10. 当前实际命中的相位 `aspects[]`。

总数是投影事实，不是常量。当前十体且宫位可用时为 `50 + aspects.length`：默认盘有 23 条相位，
因此为 73 卡；本轮换 UTC 后实算盘有 20 条相位，因此为 70 卡。profile、TypeScript 类型、模板绑定、
摘要与 UI 均使用当前实际值，没有把 73 固化为通用合同。

## 4. 隐私边界

动态模板的创建函数只接收 `WesternContentProjection`，不接收 Worker 原始结果、规则工件 request 或
页面 form。模板明确不包含：

- 姓名、出生日期／时间、地点和任何直接身份字段；
- UTC、`inputLabel`、request/requestSha256；
- 宫制选择、RAMC、地理纬度、黄赤交角、恒星黄道开关与岁差输入；
- 原始 Worker 星历、速度、有限差分或应用存储键。

但模板仍包含精确落座度数、落宫、轴点、相位、守护链与事实 hash。这些派生事实可以形成可关联、
甚至辅助反推时空的“星盘指纹”，所以只能称“移除直接身份字段”，不能称匿名化。UI 明确提示用户
把文件视为敏感资料，并由用户自己决定是否交给外部审稿人。程序不自动上传、不自动缓存；主动下载
是唯一文件输出。

## 5. 审稿与失败关闭

允许逐项填写：`unresolved / approve / revise / reject`、条件化方向提案、传统口径、决定理由、成立
条件、反例、退修要求与补充 HTTPS 来源。任何人工输入都必须同时提供 reviewerId、显示名、专业
说明、合法 ISO 时间、方法和传统范围；身份仍固定为自述、未核验、无签名。

未裁决项的全部人工字段（包括补充来源）必须为空；已裁决项必须有非 unresolved 方向、传统、理由、
成立条件与反例；只有 revise 可以且必须填写退修要求。声明计数必须与逐项决定完全一致。

UI 生命周期：

- 初始、非法输入或 Worker／规则层失败：无当前盘，下载与导入禁用；
- 成功计算：激活当前投影和动态实际计数；
- 重算一开始：旧投影、旧异步 token 和旧预览立即失效；
- 新盘成功：只启用新盘上下文；
- 错盘、篡改、编码、体积或契约错误：先清空旧动态预览，再显示失败；
- 43 项基础审稿的预览与计数始终独立，不被动态导入、篡改或重算清除。

所有结果边界仍为：identity/signature/scientific validity/formal activation/auto integration/network
transmission/storage mutation/primitive inheritance/deterministic outcome 均为 `false`，
`goodBadOrientation / eventOutcome / result` 均为 `null`。

## 7. 历史证据与本轮边界

历史 v0.5 Edge + Chrome 8/8、v0.6 聚合 16 文件 / 110 项、Schema 16 故障矩阵、Android、JPL 与其他
长门均未在本轮重跑，不能混写成本轮新证据。本轮只新增上节明确列出的 v0.7 工程门和相关 v0.6
回归。

本轮没有运行全量仓库 Vitest、Firefox、固定 Android、真实系统安装、JPL 官方字节或专家验收。
工程快照 hash 不是数字签名；自述审稿不是身份认证；来源存在不等于科学验证；全卡 approve 也不
生成吉凶或事件结果。西洋包仍是隔离草案，没有进入默认 Web 正式入口；普通发布仍是 legacy-v13，
也没有绕过 mutation epoch、创建 v16 数据或提升 v15/v16 默认代。

## 8. 2026-08-13 后继目标（不并入本页 v0.7 证据）

在线来源与当前源码复核后，下一最小安全项定为 **v0.8 七传统星体本质尊贵 occurrence 事实包**：首版只处理热带黄道下的日、月、水、金、火、木、土，以及入庙、擢升、失势、落陷四种星座级事实；绑定来源表版本、当前事实和有序 occurrence 摘要。不做三分、界、面、互容、尊贵点数、强弱排名、吉凶或事件。

定位星链的 `termination:"domicile"` 只表示链到达守护星本垣后终止，不能冒充已经实现本质尊贵。日夜、角宫、顺逆、速度和日光关系属于另一个偶然状态事实层；恒星黄道请求应保持 unsupported。本计划详见 `术数内容新目标与来源路线图-2026-08-13.md`，不要求更换当前锁定 Astronomy Engine，也不解除 JPL 官方字节、专家真值或正式入口阻塞。
