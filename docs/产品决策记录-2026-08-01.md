## 2. B 主产品定义

**工作定义：** 面向海外中文用户的一份可追问的东方人生说明书。确定性引擎负责排盘，规则层负责证据，AI 负责把专业术语讲清楚，并围绕情感、事业和自我探索继续交流。

### 首版主路径

```text
选择当前问题
  → 输入出生日期、时间和城市
  → 确认时区与准确度
  → 确定性八字排盘
  → 阅读三条有依据的核心观察
  → 反馈符合度
  → 围绕一个真实问题追问
  → 登录保存与跨设备继续
```

### 首版五个入口

1. 今天：继续问题、阶段复盘、收藏洞察；
2. 命盘：四柱、五行、十神和依据；
3. 问哈基米：基于命盘证据的连续对话；
4. 报告：基础、关系、事业和阶段专题；
5. 我的：档案、权益、记忆、隐私、导出和删除。

## 3. A 大陆版定义

A 不采用“同一个 B 产品根据 IP 地址隐藏几段文案”的方式。它是独立构建、独立内容策略和独立发布审查的文化自我探索产品。

### 默认实施方向：A0

- 历法、节气与传统文化知识；
- 用户自己选择现实主题；
- 日记与结构化复盘；
- AI 只依据用户实际描述整理和提问；
- 不用出生资料推断性格；
- 不生成个人运势、吉凶、流年、合盘或付费命书。

如果以后希望进入 A1“只展示个人历法结构”的路线，必须先用具体页面、典型输出和收费对象完成大陆律师及属地实质预审。

## 4. 15～17 岁用户的暂定处理

用户给出的品牌年龄范围包含未成年人。为了不把未成年人出生资料、命运标签和自动化营销带入首版，当前默认分层为：

### 18～35 岁

- 可以使用完整 B 版命盘、报告和 AI 追问；
- 可以在适用地区购买获准的数字内容；
- 仍需完成年龄提示、隐私同意和高风险内容边界。

### 15～17 岁

- 只开放无需账号的文化学习和一般自我反思内容；
- 不收集出生时间、地点和关系档案；
- 不生成个人命盘、性格标签或未来解释；
- 不提供个性化营销和付费功能；
- 不保存自由对话与长期记忆。

这仍然可以让品牌服务 15～35 岁人群，但完整个性化产品首版按 18+ 运行。如果未来一定要让 15～17 岁使用完整 B 功能，应作为独立的未成年人合规与产品项目评估，而不是直接放开年龄开关。

## 5. 设计借鉴原则

### 可以从问真八字学习

- 专业工具打开后直接进入核心任务；
- 命盘信息密集但有明确层级；
- 四柱、十神、藏干等数据适合纵向对齐和快速扫描；
- 专业字段可展开，不强迫新手一次理解全部；
- 历史档案、备注和继续分析形成工具效率。

### 不能复制

- Logo、产品名、吉祥物、图标和插画；
- 页面截图、文案和术语说明原句；
- 完全相同的色值、间距、卡片组合和导航顺序；
- 其私有代码、接口、数据、课程和案例；
- 让用户误以为本产品与问真八字有关联的整体外观。

项目最终应表现为“同样专业，但更温暖、更适合新手、更强调解释依据”的原创产品。

| 事件时间语义 | Event v2 只允许三种明确语义：所有旧 Event v1 记录迁移为 `legacy_floating`，新建非分钟记录为 `calendar_date`，新建分钟记录为 `zoned_minute`。后者必须持久化 IANA 时区、DST 候选与显式决策、偏移及规范 UTC；DST gap 拒绝且不平移，overlap 必须选择 earlier 或 later。旧浮动记录不得原地“转换”：只有用户显式确认后，才以新 ID 并列派生目标并追加 Event 专用回执；分钟目标固定 IANA 2026c/DST，非分钟目标固定为 `calendar_date`，源记录保持不变。 |
| Event 派生回执 | 回执授权固定为“本地用户显式确认”，绑定源/目标 ID、两端时间与研究谱系快照、摘要、解释及创建时刻。一个源可按不同 IANA/DST 解释并列派生多个目标；只拒绝完全相同的源+目标快照派生，且一个目标只能归属一条回执。回执 append-only；源/目标时间字段与回执绑定的 Case/Revision/TransitNodeRef 不可原地改写，但内容字段和软删除/恢复等生命周期仍可编辑。Citation/Attachment 不自动复制或改绑。 |
| 时区版本与历史执行边界 | IANA registry 保留 2026c/2025b；CandidateSet 并列复算与 receipt v2 已通过 Edge。另建立本命盘 executor registry，当前只登记 bazi 0.4.0 完整六字段 descriptor；exact Revision 可按两份 bundled tzdb 只读复演，完整性/engine/tzdb/rule/precision/DST 任一不支持即失败关闭。UI 零写入。relations/luck 已有严格 composite descriptor registry，Transit 1.2 已有完整快照 executor；它们只用于显式版本投影或精确收据复演，不扩大本命 Revision 精确复演范围。其他历史 bazi engine、更多 relations/luck 代际、Transit 1.1 完整 executor、Chrome/Firefox/Android 与跨代 registry 仍是缺口。 |
