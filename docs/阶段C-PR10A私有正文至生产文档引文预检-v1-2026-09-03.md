# 阶段 C：PR10A 私有正文至生产文档／引文预检 v1

日期：2026-09-03  
状态：同进程、零写入、候选预检；现实正文成功路径未执行

## 1. 本轮关闭的接口缺口

既有 PR10A private current-line runner 能用同一 held Buffer 核验一个 profile 的正文与两条 minimal quote，但它没有回答“这份 raw Wikisource wikitext 经生产 Knowledge Core 规范化后，能否形成本机私有 `KnowledgeDocument` 和行级 Citation 候选”。本预检填补这一点，不新增 zero-instance JSON 账本，不写 storage，不创建正式记录。

实现：

- `scripts/bazi-private-exact-quote-pr10a-local-private-import-preflight-lib.mjs`
- `scripts/verify-bazi-private-exact-quote-pr10a-local-private-import-preflight.test.mjs`
- 现有 runner 只新增一个最小 WeakMap／一次性 consumer capability，把真实进程内 receipt 与原 held Buffer 绑定。

## 2. 必须是同一进程的真实品牌

生产预检先运行既有 `verifyBaziPr10aPrivateExactQuotesFromFixedPrivateRoot`，再完成 production Knowledge Core runtime 的加载、server close 与临时 cache 清理；只有这三步全部成功后，才用未序列化的进程内 receipt 品牌一次性取得同一个 held Buffer。这个 Buffer 不通过公共返回值暴露；fixture receipt、spread／clone／`structuredClone`／JSON 序列化副本和调用方自造 capability 都不能消费它。

投影计算完成后，runner 会再次执行既有 authorization／body／目录／inventory 复核；租约状态固定为 `available → leased → completing → deleted`，只有后置 revalidation 通过才从 WeakMap 移除该引用并签发 preflight receipt。投影失败会 abort 本次占用并允许同一有效 receipt 重试；进入 `completing` 后不能 abort。后置复核发现漂移则删除已失效的材料关联，不签发 receipt，也不恢复旧 receipt。这仍不排除 ABA。代码不声称进程内字节已清零；`privateBytesZeroized` 仍未建立。

## 3. 直接复用 production Knowledge Core

预检没有重写正文规范化、section 生成或 Citation 引文提取算法。它用当前工作区已安装的 Vite SSR module runner 在同一 Node 进程中直接加载：

- `packages/knowledge-core/src/index.ts#normalizeKnowledgeContent`
- `packages/knowledge-core/src/index.ts#buildKnowledgeContentSnapshot`
- `packages/knowledge-core/src/index.ts#extractKnowledgeQuote`

loader 在调用点内惰性导入 `apps/web` 直接声明的 `vite@7.3.6`，并固定 `configFile:false`、`middlewareMode:true`、`appType:"custom"`、禁用 optimize-deps discovery，不加载工作区 Vite config／plugin。Vite 缺失、入口损坏或导入失败只返回不含路径的稳定错误码；失败的 single-flight promise 会按身份清除，后续调用可重新加载。模块图只允许 Knowledge Core、Contracts、Integrity、tzdb-core 及 root `node_modules`，显式禁止受限文件。Vite cache 只可使用 system-temp 直属 UUID leaf；关闭 server 后验证精确路径再清理。server close 失败会覆盖待返回值，cache 删除失败也只返回不含路径的稳定错误码；两者均不签发可用 preflight receipt。

这只证明本次进程调用了当前 production source exports，不证明 default build、浏览器 runtime、PWA／Service Worker 或公开主机。

## 4. 预检投影与引文分账

只返回脱敏元数据：

- raw `bodyBytes` 的 SHA-256／字节数，并在生产路径与 runner receipt raw SHA 精确复核；
- 生产规范化后的 content hash／字节数／行数／无标题 `text` section 范围；
- 每个 character-range minimal quote pin 所在的 production 行级 Citation locator；
- minimal quote hash 与完整行 quote hash，以及 minimal quote 在该完整行中恰好出现一次的机械观察。

minimal quote pin 和 production line-range Citation quote 始终是两个证据角色；即使两者文本恰好相等，也不能合并角色。“包含一次”不建立 minimal sufficiency，也不建立 `bindingCitationLocatorLinked`。

预览状态固定为：

```text
KnowledgeDocument: user_knowledge_document (preview only)
SourceRights: user_import / user_unverified / local_private_only / unreviewed
Citation: user_candidate (preview only)
```

返回值不含正文、minimal quote、完整行 quote、private root／路径、authorization ID 或 authorization raw digest。
