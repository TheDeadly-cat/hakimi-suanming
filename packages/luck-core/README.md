# @hakimi/luck-core

`luck-core` 是可复算的运限事实底座，不负责吉凶、旺衰、格局或事件预测。

当前 `v0.1.0` 固定实现并显式版本化以下规则：

- 年干阴阳配性别定顺逆：阳男阴女顺，阴男阳女逆；性别未知时必须人工指定方向，或由规则显式拒绝。
- 顺取出生后的下一个“节”，逆取出生前的上一个“节”；恰好出生在节令秒时，起运时差为零。
- 三日一岁精确折算：一年十二月、一月三十日、一日二十四时；保留源时差毫秒、精确有理数和未舍入组件。
- 交运时刻按固定 `UTC+08:00` 日历依次加年、月、日、时间，月末使用 `constrain`；大运区间采用 `[start, endExclusive)`。
- 十柱大运从月柱按顺逆各移动一位起算，不含上游 `DaYun(index=0)` 的童限占位段。

## 目前不能确认的规则

- 不同传承对“节/气/最近节气”、出生恰逢节令、起运年月日舍入、虚岁展示及交运时刻算法存在分歧；当前实现只是工作默认。
- `lunar-typescript@1.8.6` 的节令时间使用固定 `UTC+08:00` 秒级表。当前不把 IANA 出生地民用历法或真太阳时静默混入交运计算。
- 当前没有项目金标案例，`goldCaseCount=0` 且 `releaseGatePassed=false`。发布前至少需要覆盖男女 × 阴阳年 × 顺逆、节令前后秒级边界、闰日/月末、历史 DST 及跨日样例，并与独立历表和专家裁决结果对照。
- 1900—2100 之外、其他起运流派、按气取锚、舍入到整岁/月/日、流年/流月与断语均明确不在本版本支持范围。

调用者可传入 `expectedYearGanZhi` / `expectedMonthGanZhi` 作为集成护栏；若其规则与本包固定 `+08` 精确节令柱不一致，计算会以 `PILLAR_MISMATCH` 拒绝，而不是悄悄继续。
