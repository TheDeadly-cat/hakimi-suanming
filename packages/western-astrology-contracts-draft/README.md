# 西洋星盘契约草案

这是一个不可被生产代码导入的结构探针。它只冻结未来西洋星盘适配器所需的精确民用时间、坐标、时间尺度、星历、黄道、宫制、相位、来源和失败关闭回执；不提供星历计算，不创建数据库记录，也不代表占星专家真值。

- 包版本固定为 `0.0.0-draft.0`，`exports` 为空。
- 当前输入范围按现有冻结时区工件收敛到 `1900-01-01` 至 `2100-12-31`。
- 星历事实与占星规则分层；行星实体中心和系统质心不能混称。
- 任何星历、宫位或许可证后备路径都必须拒绝，不能静默替换用户选择。
- 当前结构样例标记为 `synthetic_contract_fixture`，所有 SHA-256 字段只做格式检查，并以 `format_only_contract_draft` 明示未由内容计算。
- 成功样例会交叉检查墙时/UTC offset、UT1/TT/TDB Julian Day、相位夹角/有向 orb/运动方向、星历工件 target inventory、请求/生效选项、零 warning，以及 profile 与回执的精确工件集合。
- `local_evaluation_only` 只表示受控本地研究范围，不是法律审查结论，也不授予再分发、公开服务或商业使用权。
- Swiss Ephemeris 只列为待许可审查的候选；当前成功工件明确拒绝 Swiss，不随本草案打包。

来源、许可证和未决规则见 [`../../docs/西洋星盘契约草案与来源门-v0.1.md`](../../docs/西洋星盘契约草案与来源门-v0.1.md)。
